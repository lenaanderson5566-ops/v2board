# 原后台布局与控件还原

继续使用 React/TypeScript。原后台静态构建 `public/assets/admin/res_005.js` 和原 CSS 是对照基线；生产页仅加载 React 业务代码及原 CSS/字体资源，不执行原后台 JavaScript。主题配置移除，自定义页脚 HTML 保留在系统配置；原运营中台继续接入统一导航。

## 验证与边界

- 90 项前端测试：金额元/分往返、空价格与显式免费价格区分、旧逗号数组兼容、Markdown/HTML 兼容，以及已有接口、联动、排序和八种语言检查。
- 184 项后端回归，事务回滚；生产构建及 TypeScript 检查通过。
- 浏览器在本地临时记录上保存并回读 Markdown 标题/表格与 19.99 元套餐价格；检查生成表单、表头排序、周期多选搜索和金额/比例切换。测试记录结束后清理。
- 本报告是布局、控件和业务兼容核对，不是所有分辨率的逐像素截图比较。真实 SMTP 投递、Telegram Webhook 与支付结算需在具备对应外部环境时单独验收。

本次补充：节点和公告标签恢复可输入、可移除的多选标签，不再要求手写 JSON。金额回读同时确认空价格周期不会被转成免费周期。JSON 编辑器格式化/全屏、支付网关参数加载、八类节点表单和页脚 HTML 已在浏览器打开核对。

390px 窄屏已验证折叠侧栏、导航后自动收起、生成用户全宽抽屉；验证后恢复默认窗口尺寸。用户右键菜单展开全部行操作，保留表格中的更多操作入口。
