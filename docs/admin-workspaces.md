# 后台经营、邀请和活动视图

仪表盘分为经营概览、访问与转化、风控概览、系统监控。旧路由不再重定向。

经营概览按 CNY / USD 切换，显示今日、本月、上月已支付订单金额、支付笔数、平均支付金额和上月同期变化；订阅与充值、已发放和待审核佣金分开展示。订单金额按 `paid_at` / `total_amount`，排除未支付与取消订单，余额抵扣不重复计为收款；零元订单计入笔数。金额不是渠道结算或净利润。同比基数为零时不展示百分比。上月同期采用相同日期/时刻，短月截断至月末同一时刻。金额和笔数独立图表，30 天无订单日期补零。财务汇总四条聚合查询，缓存 60 秒，采用应用配置时区。旧收入字段保留供既有接口调用。

访问与转化只保留访问概览、购买转化、体验问题。访问概览集中会话、趋势、来源与浏览器；业务漏斗与浏览器付款视图分开，进入付款不代表支付成功。不再展示小时/星期分布、重复改进工作台和页面列表。登录与订阅质量移到风控概览、历史健康移到系统监控、支付与邮件送达移到邮件日志，均展开后才请求数据。

安全与风控中的菜单、标签、资源编辑标题统一标记“订阅访问黑名单”；只作用于订阅获取请求，不封禁网站登录或节点代理流量。路由及实际拦截行为不变。

邀请管理使用既有 `user/fetch` 查看邀请关系，支持邀请人邮箱筛选；`order/fetch?is_commission=1`
查看佣金订单，默认待确认，可切换有效、已发放、无效和全部。审核继续使用 `order/update`。
已发放/未支付/取消/无佣金的订单不可审核。订单管理默认隐藏佣金列、详情记录和审核入口。

`user/fetch` 新增 `last_connected_at` 和邀请人 `invite_email`。
上次连接采用该用户流量活动时间 `t` 与节点 `alive` 最近上报时间的最大值；并非握手精确时间，
不代表实时在线。缺少记录返回 null。按当前分页批量查询，无逐用户数据库查询。
`last_login_at` 沿用已记录的成功登录时间。默认显示连接、登录和上次订阅时间，佣金/权限组/设备数按需切换显示。

运营中台分组移除：在线用户归用户，Banner 归用户。
订阅管理包含订阅套餐、订阅多语言两个标签，旧 `#/translations` 打开多语言标签。
系统监控独立入口移除，旧 `#/system` 和 `#/queue` 打开仪表盘系统监控标签。
日志设置统一管理连接采样间隔和各类保留时间，系统日志只查询日志；旧 `#/risk-settings` 打开日志设置。
`system/logRetention` 读写增加 `connection_log_interval`（60–86400 秒，默认 3600），与原风控接口共用配置，保存后清除采样缓存。
`last_subscribe_at` 为订阅日志中最近的获取订阅时间，按当前分页批量查询；无记录返回 null。
用户活动独立列表和菜单已移除，旧 `#/usage` 链接打开用户管理；日志中的单用户活动详情保留。
本次未新增用户端 V10 API，也未变更节点上报、佣金结算或日志保留策略。
