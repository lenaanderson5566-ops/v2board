# 后台经营、邀请和活动视图

仪表盘分为经营概览、访问与转化、风控概览、系统监控。旧路由不再重定向。

经营概览按 CNY / USD 切换，显示今日、本月、上月已支付订单金额、支付笔数、平均支付金额和上月同期变化；订阅与充值、已发放和待审核佣金分开展示。订单金额按 `paid_at` / `total_amount`，排除未支付与取消订单，余额抵扣不重复计为收款；零元订单计入笔数。金额不是渠道结算或净利润。同比基数为零时不展示百分比。上月同期采用相同日期/时刻，短月截断至月末同一时刻。金额和笔数独立图表，30 天无订单日期补零。财务汇总四条聚合查询，缓存 60 秒，采用应用配置时区。旧收入字段保留供既有接口调用。

访问与转化只保留访问概览、购买转化、体验问题。访问概览集中会话、趋势、来源与浏览器；业务漏斗与浏览器付款视图分开，进入付款不代表支付成功。不再展示小时/星期分布、重复改进工作台和页面列表。登录与订阅质量移到风控概览、历史健康移到系统监控、支付与邮件送达移到邮件日志，均展开后才请求数据。

安全与风控中的菜单、标签、资源编辑标题统一标记“订阅访问黑名单”；只作用于订阅获取请求，不封禁网站登录或节点代理流量。路由及实际拦截行为不变。

邀请管理使用既有 `user/fetch` 查看邀请关系，支持邀请人邮箱筛选；`order/fetch?is_commission=1`
查看佣金订单，默认待确认，可切换有效、已发放、无效和全部。审核继续使用 `order/update`。
已发放/未支付/取消/无佣金的订单不可审核。订单管理默认隐藏佣金列、详情记录和审核入口。

`user/fetch` 新增 `last_connected_at` 和邀请人 `invite_email`。
上次连接采用该用户流量活动时间 `t` 与节点 `alive` 最近上报时间的最大值；并非握手精确时间，
不代表实时在线。缺少记录返回 null。按当前分页批量查询，无逐用户数据库查询。
`last_login_at` 沿用已记录的成功登录时间。默认显示连接、登录和上次订阅时间，佣金/权限组/设备数按需切换显示。

运营中台分组移除：在线用户归用户与支持，横幅归营销与内容。
套餐与订阅包含套餐列表、套餐翻译、价格与币种；系统监控位于仪表盘内。
采集与保留策略统一管理连接采样间隔和各类保留时间，系统日志只查询日志。旧地址不提供重定向。
`system/logRetention` 读写增加 `connection_log_interval`（60–86400 秒，默认 3600），与原风控接口共用配置，保存后清除采样缓存。
`last_subscribe_at` 为订阅日志中最近的获取订阅时间，按当前分页批量查询；无记录返回 null。
用户活动独立列表和菜单已移除，旧 `#/usage` 不再兼容；日志中的单用户活动详情保留。
本次未新增用户端 V10 API，也未变更节点上报、佣金结算或日志保留策略。

财务性能：整个 getOverride 响应统一缓存 60 秒，包括旧年度收入字段和佣金计数，避免只缓存 financial 后仍重复扫描订单。缓存未命中使用互斥锁并二次检查，等待超时返回可重试的 503，不并发重复扫描。新增订单支付时间、待审核佣金和佣金创建时间索引，已纳入安装 SQL 与 update.sh。首次升级创建索引的耗时取决于订单表规模；索引不会改动账务金额。新安装 SQL 同时去除误加到 failed_jobs 的 daily_archived 列，该标记仅属于节点统计快照。


## 按侧栏顺序的页面检查与处理

本轮以现有功能和组件为边界，不新增仪表、导航层级、数据采集或后台接口。下表区分本轮修改与检查后保留的设计。检查依据为页面源码、共享组件和组件回归，不代表已完成真实浏览器逐屏视觉验收。

| 导航 | 评估与处理 |
| --- | --- |
| 仪表盘 | 保留四个按需切换的视图及币种隔离；不增加重复指标。复测首屏不请求访问分析。 |
| 用户管理 | 更多操作改为不依赖原生 Popover 的浮层，统一间距并支持键盘与焦点恢复；删除、重置增加请求锁及提交反馈。保留编辑、分配订单和统一用户抽屉。 |
| 在线用户 | 保留活跃时间窗口说明、分页、用户抽屉；不包装为实时在线或增加轮询。 |
| 工单管理 | 移除与状态下拉框重复的状态快捷按钮，保留邮箱、状态、回复状态和重置筛选。 |
| 知识库 | 保留预览、分类和统一编辑器；共享删除锁保护删除操作，预览继续使用清洗后的内容。 |
| 套餐与订阅 | 内部标签切换增加保存中阻止及未保存确认，保留三个业务标签与独立币种价格。 |
| 订单管理 | 保留筛选、订单详情和用户抽屉；不把佣金审核重复放回普通订单页。 |
| 支付与充值 | 移除重复的“切换启用”按钮，保留统一开关；删除增加锁、对象名称、页内错误和提交反馈。充值规则不再请求套餐及权限组。 |
| 优惠券管理 | 保留模板、活动、多语言、发放及记录的现有分工；通用列表删除使用共享保护。 |
| 礼品卡管理 | 保留生成字段联动、分页和类型单位；共享删除保护，不新增批量危险入口。 |
| 邀请与奖励 | 保留邀请关系与佣金订单分页、状态限制；佣金规则页不加载无关套餐及权限组。 |
| 公告管理 | 保留预览和统一编辑器；共享删除保护。 |
| 横幅管理 | 保留图片预览、位置和发布状态；原有操作忙状态及删除确认保留。 |
| 节点管理 | 复制、删除增加请求锁及统一反馈；列表、DDNS 和 IP 管理补齐错误重试；IP 管理轮询在隐藏、忙碌、加载或错误时暂停。部署授权协议不变。 |
| 节点权限组 | 保留精简表格和编辑；共享删除保护。 |
| 路由管理 | 保留内核筛选与规则编辑，避免混用 V2Box/V2Node；共享删除保护。 |
| 专用客户端下载 | 保留平台与架构选择及安装包选择器；不再请求无关套餐、权限组。 |
| 客户端访问与接入 | 视图切换使用正式路由，保持侧栏与实际页面一致，经过全局离开保护；服务入口不加载无关选项。 |
| 第三方客户端 | 推荐编辑增加未保存及保存中标记；镜像任务仅在可见、空闲且请求成功时轮询，卸载移除定时器。 |
| 账户与注册 | 保留分组设置与敏感操作保护；移除无关选项请求。 |
| 风控规则 | 保留场景筛选、阈值编辑及“记录不等于拦截”的必要说明。 |
| 订阅访问黑名单 | 保留 IP/UA 标签及作用域说明，使用共享删除保护。 |
| 节点访问目标 | 保留节点/周期筛选和分页，不在列表自动加载全部历史；继续使用本轮之前完成的日汇总查询及异步清理优化。 |
| 访问日志 | 保留各日志类型标签、筛选、统一时间和用户抽屉。 |
| 邮件发送日志 | 保留投递状态筛选、分页与按需详情；不默认展开送达统计。 |
| 客户端运行记录 | 保留分页和按需详情，共享表格、空状态和用户详情入口。 |
| 系统日志 | 保留筛选、分页和错误重试，不混入保留策略编辑。 |
| 采集与保留策略 | 保留分类、缩短保留期确认及清理进度，不引入自动刷新整页。 |
| 站点设置 | 仅基础信息加载试用套餐；浏览器引导和页脚不加载套餐或权限组。 |
| 通知设置 | 邮件和 Telegram 不加载无关选项；保留测试发送及凭据设置状态。 |
| 字典维护 | 保留节点地区和客户端识别两个独立分类、分页与版本冲突保护，不合并 GeoIP。 |

共享 `useData.reload` 现在保持引用稳定，避免编辑或父组件重绘反复重置定时器。轮询遇到错误会停止自动重试，管理员可使用现有重试入口。所有新请求锁仅改善前端操作可靠性，不替代服务端鉴权、事务或幂等校验；没有放宽删除确认、管理员权限、HTML 清洗和一次性部署授权。
