# 后台工作区与统计口径

## 仪表盘

仪表盘分为经营概览、访问与转化、风控概览、系统监控。

经营概览按 CNY 或 USD 展示订单金额、支付笔数、平均金额和上月同期变化。金额按付款时间与余额抵扣后的订单应付金额统计，零元订单计入笔数。订阅、充值、已发放佣金和待审核佣金分开统计。同期比较使用业务时区的相同日期和时刻，短月取月末。上期金额为零时显示「—」。趋势可切换金额和笔数，无订单日期计为零。

访问与转化分为访问概览、购买转化和体验问题。访问概览展示采集会话、同期变化、可查询日期、每日趋势和来源网站。用户可在登录后的账户偏好中同意匿名采集，统计只覆盖成功上报的浏览器。会话按开始日归入业务时区，同期历史不足时不计算变化率。定期刷新采集配置不会重发页面浏览或延长闲置会话。

购买转化使用两组独立数据。订单报表统计已完成七天观察期的普通注册账户。周期套餐按可确认的首笔有价订单判断，独立额度包按窗内至少购买一次判断，整体付费人数是两类账户的并集。付款依据为渠道回调或余额扣款。人工确认、来源不明、零价开通、充值和重置不计入，可能更早的已确认周期订单缺少付款时间时，后续订单不能判作首购。

站内购买路径按所选设备的全部采集会话、浏览套餐、确认订单、进入付款页逐步展示到达数和未到达数。每步到达率以上一步为分母。全额余额支付、零元开通及跨会话续付均可能跳过付款页。设备和来源只用于匿名访问统计，订单转化独立按账户统计。

成熟批次保留业务时区的完整注册日期：先从当前瞬间减去 604800 秒，再取该时区当天零点作为不包含的结束边界，向前取所选天数。这样夏令时切换也保证所有入选账号已观察至少 168 小时；注册日期范围为起点包含、终点不包含。首购付款窗口同样按实际秒数计算，包含注册时刻，排除恰好满 604800 秒及之后的付款。

体验问题按查询窗口和设备展示上报过异常的会话占比。同一会话在总览只计一次，在页面和异常类别明细中可出现多次。只有页面浏览的会话也计入分母。零样本时不显示百分比。页面性能按指标展示样本数和 P75、P95 桶上界。

经营汇总包含各币种数据，缓存 60 秒。并发刷新复用已生成的结果，等待超时返回可重试的 503。待回复工单数在读取时单独查询。`stat/getOverride` 继续为既有调用提供旧版收入字段。

## 邀请与订单

邀请管理使用既有 `user/fetch` 查看邀请关系，支持邀请人邮箱筛选；`order/fetch?is_commission=1`
查看佣金订单，默认待确认，可切换有效、已发放、无效和全部。审核继续使用 `order/update`。
已发放/未支付/取消/无佣金的订单不可审核。订单管理默认隐藏佣金列、详情记录和审核入口。

订单列表的「用户（ID / 邮箱）」直接打开与其他后台页面共用的用户详情抽屉，可查看账户概况、当前套餐、历史订单与额度包。用户列表、订单、工单和日志中的身份入口统一使用白底描边按钮，悬停显示浅灰底色，不使用紫色链接文字或下划线。关闭后保留订单筛选和分页；订单详情与更多菜单中的原入口继续可用。缺少用户 ID 时保留身份文本。

订单的「首购」使用与转化报表一致的有价周期订单口径，按已确认付款时间及订单 ID 取首笔。余额支付计入，免费试用、纯折抵、独立额度、充值和重置包不占用首购资格。已有更早付费周期订单的原「新购」订单统一显示「再次购买」，不受有无到期快照影响；有可能更早的已确认有价订单缺少付款时间、尚未付款或零价等无法确认购买阶段的周期订单显示「周期购买」。续费和变更套餐仅显示业务类型，详情另列「购买记录」首购或再次购买，不在列表拼接多个分类。原类型已显示首购或再次购买时，详情不再重复购买记录。

再次购买的到期证据在详情独立展示。新增只读 `repurchase_expiry_status` 区分 `expired`、`not_expired` 与 `unknown`，原 `purchase_stage` 保留兼容。下单时保存的原周期到期时间已到期，且先前付款不晚于该到期时间时，详情紫色标注「到期回购」，按实际经过的 24 小时展示间隔。原期限晚于下单且付款顺序有效时显示「有效期内购买」；缺少快照、时间无效或顺序矛盾则显示「到期情况不详」，不把缺少证据当成未到期。旧响应中的 `expired_repurchase` 仍可识别，但新字段优先。首次购买不显示回购情况。

原到期时间保存在订单的独立可空字段，后续订单更新不会改写。旧订单不回填或按订单间隔、当前用户期限推算到期；已确认的再次购买仍可展示，无需补齐历史到期证据。历史订单按实际购买周期和有效额度快照显示「额度购买」或「流量重置」，不依赖套餐名称和当前价格。原数字类型、订单金额和履约逻辑均不改动。

## 用户管理

用户列表可在「显示设置」中调整列。周期套餐到期时间在列表显示到分钟，用户抽屉保留秒数。有效期内使用绿色，七天内到期使用橙色，已到期使用红色。

`user/fetch` 按页返回邀请人邮箱和最近活动时间。「上次连接」取流量活动时间与节点最近上报时间中的较晚值，「上次登录」取最近一次成功登录，「上次订阅」取最近的订阅请求日志。缺少记录时显示空值。权限组和设备数可在「显示设置」中开启。

「累计实付」按账号币种合计已确认的外部付款本金，包括余额充值、直接购买周期套餐或额度包等订单。充值后再用余额消费时，仅计充值本金。混合支付仅计外部付款部分。已确认但尚在开通或入账的付款、后来用于套餐折抵的历史付款仍计入。佣金转入、人工确认、赠送金额、手续费、待支付及取消订单不计入。

用户抽屉和访问日志可通过 `risk/user-activity/fetch` 查看单个用户的活动。「在线用户」按活跃窗口查询。原独立用户活动列表和 `risk/user-usage/fetch` 已退役。

到期时间为空或默认值时，如账户没有周期流量，且留存订单中没有开通中、已完成或已折抵的周期订单，列表和抽屉显示「尚未购买周期套餐」。人工开通和零元周期订单同样保留历史依据；已有周期订单但到期时间未知时显示「到期时间未记录」。

尚未购买和周期权益未开通使用灰色标签。旧版流量无固定到期、到期时间未记录或到期信息缺失使用蓝色标签。

用户列表仅在账户有具体期限和基础流量时显示关联的周期套餐名称。首次购买额度包时，关联商品可能只用于分配节点权限。抽屉的「账户概况」分别显示当前周期套餐、周期到期和可用独立额度，周期流量用完后套餐名称仍显示至到期。「查看额度批次」按需打开现有的额度包页签，可查来源、剩余量和各批到期时间。旧版无固定到期流量单独标注。

## 套餐与订阅

「周期套餐」包含周期商品、未定价草稿和仅配置流量重置价格的商品。「额度包」展示已配置一次性额度价格的商品。混合商品在两个页签共用商品 ID 和通用字段，各自编辑价格。两个列表都支持查看全部商品。

两页的统计列均为「有余量人数」。周期套餐统计当前套餐有效且基础流量尚有剩余的用户。额度包按原商品统计未到期且有剩余的订单批次，同一用户只计一次，无商品订单关联的赠送或迁移额度不计入。

## 设置与日志

| 入口 | 用途 |
| --- | --- |
| 系统设置 → 账户与注册 | 注册方式、邮箱验证、注册限制和试用在「注册设置」中管理，后台入口、登录保护和账户删除在「账户安全」中管理。 |
| 系统设置 → 通知设置 | 配置邮件、Telegram 和邮件禁发名单。 |
| 系统设置 → 采集与保留策略 | 管理采集开关、保留期限和连接采样间隔。缩短期限前会要求确认。 |
| 订阅访问黑名单 | 按 IP 或 UA 限制订阅获取请求。 |
| 日志与诊断 | 查询访问、系统、邮件日志和节点访问目标。用户、订单和日志中的身份按钮均可打开共用用户抽屉。 |

连接采样间隔由 `system/logRetention` 的 `connection_log_interval` 配置，范围 60–86400 秒，默认 3600 秒。与风控页面共用配置。

节点管理、支付诊断与通用按钮的交互细节分别见[节点管理](node-management-ui.md)、[后台诊断](admin-diagnostics.md)和[后台组件](admin-components.md)。
