# 客户端导入语言

用户配置页一键导入、复制和二维码都使用带 language 参数的订阅 URL。支持站点全部八种语言。客户端自动更新继续沿用导入时的语言；用户修改语言后可重新导入或更新 URL。

旧链接没有 language 时，使用用户数据库语言；再回退请求语言和简体中文。系统提示节点按此语言展示，不再同时插入多语言重复提示。到期与计划重置时间包含分钟和站点时区。管理员自定义节点名称和规则模板不自动翻译，以保留节点标识及规则引用。

网页只表示已尝试唤起客户端，不能确认第三方客户端实际导入成功。复制成功后提供粘贴/更新步骤，无效订阅地址显示可恢复提示。内置浏览器仍使用现有手机浏览器引导。

无数据库迁移，不调用翻译服务。验证：php tests/client-import-language.php；npm test -- --run src/import-links.test.ts；npm run build。
