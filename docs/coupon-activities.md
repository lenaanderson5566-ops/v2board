# 优惠券活动与多语言

用户在「活动中心」了解优惠并领取，在账户菜单「我的优惠券」查看券包；购买套餐时仅选择已持有的券。公开领取沿用 V10 coupon-offers / coupon-claims 接口，服务端仍校验库存、有效期及每用户限领一次。历史订单已经使用过该券的用户不会再看到可领取活动，避免重复领取。

后台「优惠券 → 活动与多语言」配置默认活动标题、纯文本说明，以及简体中文、繁体中文、英语、日语、韩语、越南语、俄语、波斯语的券名称及活动文案。默认券名称仍在模板管理中修改；公开领取开关仍由模板管理控制。翻译可以逐字段留空，回退到对应默认文案；未设默认活动标题则使用当前语言的券名称。不自动翻译管理员的商业文案。

用户接口按 Accept-Language 协商语言，私有响应禁止缓存，不返回完整翻译映射或优惠码。折扣、库存、有效期及套餐限制只有一套。领取或确认批量发放时冻结翻译和优惠规则，修改模板不改变已发出的券。旧券快照没有翻译字段时兼容默认名称。
