# 关键配置复查

对照基准：原后台 `public/assets/admin/res_005.js`，并以现有后端校验和实际读取逻辑验证字段语义。

| 页面 | 发现的问题 | 修复与验证 |
| --- | --- | --- |
| 节点配置 | Hysteria 混淆、TUIC UDP 和拥塞控制选项缺失 | 恢复版本对应的 xplus/salamander、native/quic、cubic/new_reno/bbr；切换版本清除旧混淆参数 |
| 节点配置 | 证书及 Reality 子参数依赖高级 JSON | 增加证书模式、DNS provider/env、证书文件路径、Reality dest/xver；DNS 与 Reality 条件切换在浏览器核验 |
| 节点配置 | 非 VLESS 协议也出现 Reality；AnyTLS 可选不适用传输 | 限定 Reality 到 VLESS；必需 TLS 协议自动同步，AnyTLS 使用 TCP |
| 节点配置 | VMess XHTTP 和 security 子参数缺少控件 | 增加模式、Host、加密方式；高级扩展 JSON 继续保留未识别参数 |
| 节点配置 | AnyTLS padding 数组被后端再次 JSON 解码 | JSON 输入提交时重新编码字符串；事务测试验证保存后回读数组 |
| 系统设置 | 一次性链接误标为每日轮换 | 改为一次性有效，依据 Client 中间件实际消费令牌逻辑；限时模式有效时间至少 1 分钟 |
| 系统设置 | SMTP 端口为空时被当成文本 | 改为整数端口，范围 1–65535；补充数组设置格式示例 |
| 系统设置 | 测试邮件与 Telegram Webhook 操作缺失 | 恢复按钮、忙碌状态及错误反馈；未保存修改时禁用操作；邮件服务返回错误日志不会显示成功 |
| 支付配置 | 网关 alert 说明被误当成配置输入 | 独立显示经过 HTML 清理的说明，禁止将 alert 作为参数提交 |
| 支付配置 | 未应用返回默认值；切换网关可能携带旧密钥 | 应用网关 value；更换网关清除旧配置并保留公共字段草稿；编辑同网关保留扩展参数 |
| 支付配置 | 输入 0% 手续费被后端拒绝 | 前后端一致接受 0–100%，固定手续费非负整数；保存和回读验证通过 |

覆盖八类节点保存流程、全部已安装支付网关表单读取，以及付款方式配置保存与回读。浏览器核验节点证书/TLS 条件变化、支付网关表单切换、邮件及订阅设置。外部 SMTP、Telegram、证书申请、节点服务进程和真实支付没有联调，不能据此认定外部服务已可用。

原对照报告中排序等缺失项仍保留。此次复查处理关键配置字段和保存逻辑，不表示全部后台功能已补齐。

验证结果：68 项前端测试、87 项后端冒烟检查通过，生产构建成功。测试节点和支付方式在事务内回滚；浏览器检查的草稿均未保存。
