# 前后台验证

本文维护可重复的自动检查、浏览器验收清单及结果边界。功能规则以对应说明和当前代码为准；测试归属见 [测试组织](test-organization.md)。旧日期章节、逐轮计数、合成截图和发布记录通过 Git 与原始输出查阅，不代表当前版本已经验收。

## 自动检查与产物

在可销毁副本中安装锁定依赖并执行，数据库、缓存及外部服务隔离遵守 [测试组织](test-organization.md)：

```sh
php tests/run.php --validate
php tests/run.php --only=console-smoke,console-verify,frontend-runtime
cd frontend
npm ci --include=dev --ignore-scripts
npm test
npm run build
```

构建包含 TypeScript `--noEmit`、Vite 和前后台资源拆分，会写副本的 `public/console`。专题命令以 `frontend/package.json` 为准；浏览器认证、支付、安全或节点变化同时运行对应后端模块。契约生成与校验见 [项目结构](project-structure.md) 和 [V10 审计](api-v10/audit.md)，不能因测试包含旧接口名或历史漏洞而删除拒绝断言。

CI 使用 Node 24 和锁文件执行前端全量测试/构建，将当次产物及隐藏 `.vite` 清单交给后端页面/资源验证，不自动发布。push/PR、默认 `master` 分支对 schedule/Dependabot 的生效条件及生产安装检查见 [测试组织](test-organization.md)，远端结果以对应 Actions run 为准。

发布前检查 manifest 每处文件引用、动态依赖、JSON worker、十四语言、JavaScript/JSON worker 的 ASCII 约束、前后台复制一致性及用户图不含后台源码；检查构建不包含合成账号、报价或订单。记录 gzip/原始入口体积及主要成本，但静态诊断不能代替低端真机的 LCP/INP/CLS。`update.sh` 使用已提交 `public/console`，生产无需 Node 构建。隔离产物与源码/锁一起发布；若 alternate work-tree 只暂存发布资源而保留本地运行版本，不能自动还原有意保留的工作区差异。部署细节见 [前端部署](frontend-deployment.md)。

## 浏览器环境与夹具

使用目标提交的最终构建和仅本地合成 V10 响应，分别检查桌面、320/390/768px、长文案及 RTL。每个关键页覆盖加载、空数据、请求失败、重试、429 冷却、成功和已有数据刷新；宽表在自身容器滚动，页面不横向溢出，底部操作不遮挡内容。检查键盘、焦点、滚动、标签、错误关联和关闭保护，不能只看截图。

以下 helper 仅在独立 local 环境及测试库手动运行，不属于自动测试入口：

```sh
php tests/console-ui-fixtures.php setup
php tests/user-experience-fixtures.php setup
# 完成人工检查后恢复
php tests/user-experience-fixtures.php cleanup
php tests/console-ui-fixtures.php cleanup
```

控制台夹具创建带专用前缀的隐藏内容；用户夹具要求预先存在非管理员 `test@example.com`，会备份并临时修改其套餐字段。上次恢复文件存在时不能再次 setup；清理失败先核对引用，不强删数据或恢复文件。禁止提供真实支付、邮件、云服务凭据或在生产账号上验付款、群发、删除、换 IP、证书申请。

## 通用恢复与可访问性

- 账户/会话元数据临时失败提供原地重试，不当作退出；真实认证失效仍清理会话并拒绝旧请求。后台刷新保留稳定子树、草稿、焦点和购买窗口，首次未知余额不显示零。语言失败保留当前工作区并可重试；React/运行配置未就绪也有独立十四语言恢复界面，不暴露异常或模块地址。
- 冷却显示剩余秒数，结束后只允许手动重试；秒数和日期形式的 Retry-After 都覆盖，切换输入、聚焦、重复点击及关闭重开不能绕过。浏览器初始化 15 秒包括 JSON 正文，超时清理未完成任务后可重新初始化；保留跨标签切换账号、CSRF 刷新与离线退出检查。
- 导出 60 秒超时包括响应头和正文，失败提示核对结果再重试，不自动重放生成优惠券等写操作。模拟超时不能证明生产大数据导出的耗时。
- 跳过导航不改变 hash；跨页更新标题并聚焦主内容，同页付款 query 不打断输入。抽屉关闭焦点返回有效触发控件，不留在 inert 区域；Tab/方向键排除隐藏禁用项，Esc、遮罩、关闭按钮和取消均验证。局部异常保留导航，切页可恢复。[页面结构指引](https://www.w3.org/WAI/tutorials/page-structure/)
- 登录/重置凭据输入不显示未保存提醒；后台路由保护只在登录后启用，退出和失效立即解除。普通编辑继续保护草稿。弹窗提交期间锁定，取消后重开、异步提示清理及旧请求完成不污染新状态；共享 Modal 的草稿确认须显式启用，默认关闭策略不变；原生确认接受/拒绝都验证。

## 用户入口、账户与服务

两种首页说明服务范围、第三方会员边界及付款前核价，以登录后查看套餐恢复选购，不公开鉴权价格。检查首页、注册/登录、套餐比较、结算、下载/导入、用量账单和帮助全链路，保留密码管理器、移动键盘和验证码粘贴语义。

新注册跳转区分有效试用、无服务、普通登录及明确付款/客户端授权返回；新账户总览优先恢复待支付订单，开通中只显示进度。加载或查询失败不能当作无订单；取消确认及状态恢复保留。账单首购入口仅在新账户、未筛选且成功读取后的空记录出现。手机套餐显示所选周期总价、售罄和完整长名称；单套餐省略重复选择，320px 周期按钮合理换行。邮箱验证返回编辑同一邮箱时在倒计时内复用验证码。

账单页的余额自动续费位于当前订阅卡片内，检查桌面与窄屏下说明自然换行、开关触控区域至少为 44 × 44px。订阅详情暂不可用时，已开启的用户仍可在账户数据可用时关闭自动续费。

| 范围 | 检查要求 |
| --- | --- |
| 订阅与独立额度 | `has_subscription` 区分套餐和额度；过期套餐与有效额度并存不误导。临期提醒只用服务端时间七天内、可续订的有效套餐；长期有效和不可续订不误报。额度目录/订单未知、刷新失败或冷却时禁止下单并保留选择。 |
| 下载与导入 | 保留所选系统/客户端，说明安装后返回导入；按设备排障，完成只导航、不表示连接成功。复制失败提供可选手动链接，来源变化忽略迟到反馈。多芯片安装包必须显式选择且只有一个主下载操作，不凭浏览器猜芯片。 |
| 授权与次级页 | 客户端授权失败先只读查询，批准结果未知不再次批准，已消费/过期提示回 App 核对或重发。通知按字段同步，不覆盖正在保存的乐观选择；工单、设备列表、公告、Passkey 和下载账户局部重试；佣金转入标签使用账户实际币种。 |

工单求助需覆盖订单 A 草稿切到订单 B、普通工单草稿和旧版草稿：关联订单必须可见并以当前求助入口为准。打开对话时可刷新新回复，后台、离线、请求中和限流冷却期间暂停轮询；刷新及失败不清空回复输入。创建权限加载失败须说明并可重试，不将网络失败表现为禁止创建。

客户端授权换账号必须先确认服务器会话已退出，再回到登录；撤销失败保留当前页面并可重试。只保留合法授权 ID，重新登录后再次查询请求并由用户确认，不复用旧批准结果。Mac 客户端可选项需有对应下载来源，并说明 App Store 客户端的设备兼容限制；管理员停用和镜像策略继续生效。

上述恢复流程由既有 `HelpSupport`、`PaymentCheckout`、`QuickStart`、`ClientDownload`、`ClientAuthorization`、`app` 和 `shared/api` 测试覆盖，相关账单、支付轮询、登录与浏览器会话模块一并回归。此次通过组件回归、TypeScript 检查和生产构建；发布清单资源完整且无孤立产物。尚未进行真机支付、实际客户端安装或浏览器视觉验收。
| 账单 | 状态、时间和完整订单号组合筛选全历史后分页，不仅过滤当前页；显式提交，提交/重置回首页，冷却禁用筛选和翻页。UTC 起点包含/终点排除，毫秒边界与秒级订单一致；他人/不存在订单均为空。 |
| 帮助与 iOS 账户 | 一个搜索框驱动 FAQ/文档，文章失败原弹窗重试。iOS 下载账户按需展开、默认隐藏密码、关闭即卸载凭据，长名称和复制可达；说明 App Store/iCloud 边界，停用不露密码。 |
| 配置记录 | 安全页主入口和快速开始共用独立懒加载记录页，入口不预取；成功只表示请求响应，不证明导入、连接或在线设备。本人记录、历史失败原因、未知值、IP 脱敏与估算地区保守展示；无地区不留占位。分页失败不显示旧页/伪造总数，空页无第零页，仅手动刷新。 |

### 功能开关与敏感操作

| 配置 | 关闭/变化时的要求 |
| --- | --- |
| 注册 | 登录/落地页隐藏注册，邀请页隐藏发送，历史邀请及佣金保留。 |
| 新工单 | 隐藏创建及已打开表单，按规则保留查看/回复旧工单。 |
| 套餐切换 | 有效且有额度的当前订阅按服务端限制目录和详情；合法续费、新用户及已过期用户购买仍可用。 |
| 客户端策略 | 隐藏停用选择/导入/下载；全部停用不打开空弹窗。 |
| Telegram/账户删除/iOS/Passkey/MFA | 各用自身开关。MFA/Passkey 状态读取前不闪现开启入口；关闭且无历史绑定才隐藏，有绑定保留管理/恢复。 |
| 提现与其他 | 关闭提现隐藏按钮/表单，保留佣金记录和转余额。充值奖励为空不禁止充值，多级佣金关闭不禁止直接邀请；统计关闭仍保留隐私选择。 |

运行配置开关在重新加载后应用，独立前端同步运行配置；服务端仍拒绝关闭的写操作，发起与确认之间变化也须检查。删除账户先说明登录、权益及保留影响，再列余额/订单阻碍项；读取失败暂停删除且可重试，功能关闭隐藏入口。确认保留当前密码、近期完整认证、`DELETE` 和勾选，忙时不能关闭/重复提交，取消清空确认字段。真实设备 Passkey、生产 MFA 和删除不在合成验收中执行。

## 结算、优惠与付款

结算页统一周期、优惠、具体渠道和服务端报价，桌面价格/操作集中，窄屏纵向及底部操作可达。URL 仅保留安全套餐 ID、白名单周期、券选择意图和订单查询引用，不放金额、权限或自动付款指令。返回、登录恢复及刷新保留选择；普通订阅恢复原确认页，充值/额度/重置保留专用路径。购买说明区分续订、切换和重订，不推算到期日，以已创建订单服务端类型为准。

手机布局验收重点：320px 金额与按钮上下排列，390/768px 支付网络展开不进入悬浮栏，确认栏避让 68px 导航及安全区；短视口确认栏回到文档流，长订单号不横向溢出。客服入口需避让吸附的付款操作栏，不能移动聊天会话面板。当前手机专项已完成代码检查及合成回归；本地预览无法由内置浏览器连接，Windows 界面工具也因无法可靠识别浏览器 URL 而停止，因此不记为真机或浏览器视觉验收通过。

| 场景 | 检查要求 |
| --- | --- |
| 优惠券 | 原位展开并统一随购买主体滚动，固定底部操作；选后收起并恢复摘要焦点。空/过期/已占用/不适用且无可用券时隐藏入口及间距，读取失败保留错误重试。有券未选显示预计节省，选后才显示优惠后小计；尊重主动不用券，失效清除且切回不擅自恢复。 |
| 跨页优惠意图 | 仅安全 couponId，重新读取本人券包后一次性定位适用套餐/周期；手动选择优先。失效/非本人/不适用券不入报价，已恢复订单不接受新优惠意图；失败和冷却可恢复。 |
| 滚动与布局 | 长券名、多券、原生单选、键盘焦点、禁用、触摸和 RTL；购买主体单一滚动，细滚动条稳定占位，强制颜色恢复系统样式。重置说明与卡片规格有清晰间距。 |
| 渠道与网络 | 使用配置图标和安全兜底；同币种不同网络/多渠道清晰区分，展开网络不自动选钱包，选定具体渠道并得到报价才可确认。付款中禁用；桌面与手机网络名/协议标签、二维码和按钮不遮挡。 |
| 报价缓存 | 相同完整条件/币种/语言可即时回切；30 秒及服务端到期取边界，命中不延长有效期。刷新、资产变化、页面/会话变化、容量限制和迟到响应覆盖；只读 POST 报价不广播资产变化或清钱包缓存。 |
| 重报价与冲突 | 计算期间保留明确标记的旧金额及原周期，支付选择/明细 DOM 和布局稳定，不能强制提交。成功同步金额/周期，失败局部重试；409 不循环重选渠道，服务端拒绝缓存报价后必须重新确认。优惠券失败不无故阻塞有效报价。 |
| 明确不可用的渠道 | 下单前明确返回不可用时刷新支付选项，保留原订单、金额和优惠，引导重新选择；全部不可用时有刷新与帮助入口。只有用户明确选择并确认后才能再次发起支付；未知结果仍先核对原请求。 |
| 同页付款 | 确认后锁定原周期和优惠，保持表单及地址；一次创建/付款，StrictMode 及重复点击不重放。明确确认仅短期内存交接，消费/退出/失效清理；刷新只恢复状态，不重新报价或自动付款。 |
| 未知与迟到结果 | 先查询原请求，不换标识重付；已有订单优先恢复，恢复支付携 UUID。金额/币种快照变化清旧二维码，失效渠道重读，跨标签同步和信用卡迟到回调不覆盖新状态，检查状态不再次下单。 |
| 手机付款 | 区分网关合法 web/钱包 redirect、受支持官方 HTTPS QR、普通 QR、Native 微信扫码及危险/未知协议。拒绝嵌套地址/凭据/控制符；重复打开复用入口，复制成功/失败明确，按需备用 QR 和安全滚动尊重减少动态效果。 |

购买说明按服务端 effectiveResetMethod 和 resetMethod 继承语义展示，未知配置保守处理；有效期按月数，开通以付款确认并处理完成为准，自动续费受账户设置和余额约束，不承诺固定开通时间。所有金额、折扣取整、币种和订单参数继续由后端最终核验。打开支付与复制成功后停止发送点击统计，复制失败只上报匿名错误类别。

## 后台、内容与运营

- 套餐、客户端、邀请工作区只显示一层页签，已有子页地址及邀请复核编号可直接打开。搜索命中系统监控、套餐翻译、佣金审核和日志策略子页；同页查询参数变化经过与其他后台导航相同的保存保护，支持浏览器前进后退。窄屏页签可换行，抽屉开启时焦点落在关闭按钮。
- 优惠券草稿或发放预览切页前确认，提交中的页面和弹窗拦截离开。工单队列校验深链、实际查询参数与焦点；订单内打开用户抽屉保留列表筛选。流量额度失败仍可查看服务器详情，重试回填后才能保存配置；切换邮件语言或模板后忽略旧预览响应。上述行为以组件回归验证，手机触控与视觉效果需实际设备验收。

- 搜索命中具体分组/子页，标题、地址和主内容焦点一致；手机菜单锁背景滚动/交互，初始焦点、Tab、Esc 返回正确。会话临时读取失败原地恢复，401/403 仍依权限规则处理。
- 订单显式查询与高级条件并存，可逐项移除；邮箱输入同步，迟到复制不覆盖新详情。订单号、状态、原币种金额和用户优先展示；详情/更多菜单及右键保留操作、危险确认与状态禁用。方向键支持真实链接和按钮。
- 支付目录失败不阻断列表，过期目录不允许编辑；无分页元数据不虚构下一页，空末页在成功读取后纠正。编辑错误关联并聚焦字段、失败保留草稿；未知单/多选保留，可排序表格兼容拖动/键盘及同步提交锁。
- 设置刷新保留分类与编辑基线；镜像防重复、离页停止后续提交、429 暂停批次/轮询；群发记录局部恢复，不自动重试发送。邮件重新预检先清旧人数/确认，失败不可发送；发送中不能误关，用户高级筛选也保护草稿。
- 协议文字和稳定配色用于节点、服务、部署、详情、拓扑和服务器，未知中性回退、强制颜色可读。套餐关系名优先、复用已加载目录、不逐行请求；失败不当作删除，不清未知选项，显示名称仍提交 ID。
- 仪表盘系统状态失败不阻断经营数据，统一刷新、币种隔离、趋势切换不重复请求，缺失日期断线、零值/非有限数值分开处理；图表键盘选择和明细可用。购买转化区分有价周期首购与其他订单，CNY/USD 分表，不完整快照有说明，净收入不可计算不伪造；浏览器同意样本不能替代业务分母。
- 节点新增两种方式共用搜索/名称预览/稳定地区城市代码，共享服务继承与手动保护，独立线路、TLS 身份、流量额度及表单切换均保留。路由可视化和 JSON 无损切换、逗号正则、复制、搜索、引用明细/删除保护/失败回滚；部署查询可重试，暂停后重新生成恢复，复制命令后跨离线继续观察。域名当前/候选地址、DNS/证书、回执、一次性授权及多后台隔离均核对。
- Lightsail 验共享凭据轮换确认、失败配置编辑/移除、继续/恢复、执行锁及 HTTP/cURL 诊断；Cloudflare 凭据、嵌套抽屉、风险详情和长只读文本检查窄屏、关闭和草稿保护。HTTP/cURL 不能单独证明权限、配额或资源存在。
- 公告预览/详情单回车换行、空行分段、保存原 Markdown；知识库保留其软换行规则。邮件过滤保留 CRLF/空行，避免给已有 br 或块间空白重复换行，HTML/纯文本一致；脚本、危险链接、跟踪图片继续过滤。模板、邀请、禁发和受限存储均检查。

## 时间、数量与隐私

事件时刻采用个人显示时区；UTC 与跟随设备 null 均按原 `PATCH /me` 契约保存。成功应用已确认偏好，失败保留当前值；旧缓存/请求、退出、切账户和组件卸载回调不能覆盖新状态。后台独立偏好按站点/API、后台路径和管理员 ID 隔离，缺 ID 不持久化；设备/业务/指定 IANA、非法存储、临时内存降级、重新挂载提示和跨标签来源均覆盖，不写用户偏好或业务配置。

展示切换原地重绘，不重挂载表单或重新读业务数据；日期输入、排期、筛选和报表桶保持业务时区/原有口径。业务时区修改需说明影响、两地同一时刻并确认绑定原/新值，读取失败拦截；改回原值清确认。工作区标题跨日、聚焦及恢复可见后更新，不增加账户请求。

普通记录/到期/下次重置用分钟精度，安全诊断保留秒，日期后仅一个简短 UTC 标记；整点、零、正负及四分之一小时和 DST 都检查。重置待确认/待重试保留原任务状态，无重置不显示伪日期；不重复系统行。Unix 秒和明确时区 ISO 才作事件解析，非法日期不规范化、空值不变 epoch，下载账户不直出上游字符串，未来记录保守处理。历史统计日不随展示偏好移动。

后台输入按业务区保留秒，未改动的 DST 重复小时保持原瞬间；新选歧义/不存在时刻拦截，安装包发布时间与选择器同步。CSV 保留明确偏移、无期限空单元格及列结构，不输出券码/卡号明文。

数量统一 shared/number-format，语言分组与小数一致；金额整数分/明确币种、固定两位，未知显示破折号而零保留。流量按 1024 显示 B/KiB/MiB/GiB/TiB/PiB/EiB，最多两位、舍入进位，不迁移原 GiB 输入或 5 MiB 上传字节限制。计数整数；百分比通常最多一位，极小/近满额有边界提示，整数优惠比例不变；耗时保留 ms/s 维度、最多一位，小量显示阈值；极小倍率最多九位、CLS 三位及汇率六位微单位保留；进度和计算用原值，已换算 GiB 不二次换算。帮助搜索兼容旧 GB 和新 GiB。

## 内置浏览器与弱网入口

默认引导仅适用于未明确配置的微信/QQ/微博/企业微信；显式 allow/prompt/guide 优先，普通浏览器不误拦，缺失设备字段安全回退。完整入口使用真实站点名和中性说明，允许进入前不加载业务工作区；提示确认绑定当前应用/策略。复制优先，失败可选安全地址，关闭/地址变化忽略迟到反馈，RTL 正文和 LTR 链接分开。后台预览含策略草稿和系统浏览器对照，明确未写剪贴板，不嵌套主 main/h1、不提交配置，不承诺规避平台域名标记。

付款/下载/导入帮助复用 Modal，保留原订单 DOM 与选择，compact 不误提交。交接仅白名单页面及安全套餐/周期/券/订单意图，去临时凭据、授权证明和付款内容，目标重新鉴权、读取本人订单/报价，不迁移会话或自动付款。平台菜单、复制权限、系统钱包及 App 唤起须真机验收。

公开入口仅基础样式和十四语言入口词；允许进入后并行取工作区和当前完整词库，中文不附带英文全词库。词库请求去重、失败可重载，引导切语言不读身份/业务；登录前不加载账户、通知、邀请、Markdown、可选页脚过滤，实际页脚插入仍安全过滤。登录后预热必需壳，支付/详情/安全/优惠按路由加载。

源及产物静态图防止完整词库、大块业务样式和富文本回流入口。`firstViews` 包含必需工作区/当前词库/静态 JS/CSS，排除未渲染图片；口径见 [性能治理](observability-governance.md)。弱网合成测试可固定每请求延迟、共享带宽、gzip 和无缓存，对比登录、引导、语言切换/一次失败恢复及登录后工作区。记录条件和分位数限制，单次本地耗时或体积下降不能作为线上性能/转化提升证明。
