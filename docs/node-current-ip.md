# 节点当前 IP

后台节点管理列表显示“当前 IP”，不显示更新时间。支持 V2Box，子节点沿用父节点地址。

优先显示启用的 DDNS 上报中最近 15 分钟内的 IPv4 / IPv6；否则显示最近 24 小时内通过认证的节点请求来源公网 IP。未获取或缓存过期显示“未获取”。不需要启用 DDNS 即可获取请求来源地址，节点正常连接后自动更新。

请求来源是节点连接面板的出口地址，使用 NAT 或反向代理时可能与节点入口地址不同。面板位于反向代理后时，应正确配置可信代理；不会直接信任任意 X-Forwarded-For。若需准确双栈地址，请使用已有公网 IP 上报功能。

字段仅添加到管理员节点列表，不进入用户订阅。
