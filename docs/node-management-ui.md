# 节点管理界面

## 新增节点的共用展示字段

独立部署与共用现有服务的线路统一使用节点名称、国家/地区搜索、州省城市搜索、线路后缀、可创建标签和中英文名称预览控件，字段标签与说明来自 `nodeLineFields`。共用线路的权限组同样使用可搜索多选，但只能选择所属代理服务开放的权限组，倍率继续由服务统一维护。默认线路编辑也共用国家/城市联动：保留同一国家下的城市及自定义城市，切换至其他国家时清除不相符的已收录城市，清空国家时清空城市。新建共用线路未手动调整位置时跟随所选服务，手动选择或清空后不再被服务切换覆盖。

## Lightsail 失败配置管理

AWS 凭据独立在“AWS 密钥管理”中保存，服务器通过 `credential_id` 引用；同一密钥可绑定多台服务器，各自选择区域和实例。列表只返回密钥名称与绑定数量，不返回 Access Key、Secret Key、Session Token 或密文。服务器表单可直接添加密钥，成功后保留服务器草稿并选中新建项。编辑密钥留空保留原凭据；更新共用密钥必须明确确认全部绑定服务器，任一绑定服务器正在执行 IP 操作时禁止轮换。仅改名称不影响运行中的操作。被绑定密钥禁止删除，移除服务器配置不会删除密钥或其他绑定。

升级运行 `2026_10_27_000002_share_lightsail_credentials.php`：按完整的 Key/Secret/Session Token 合并相同旧凭据，保留原密文、服务器 ID 和 IP 操作状态，并移除服务器表的重复凭据列。无法解密的数据会使迁移安全停止并保留原列。`update.sh` 已包含迁移预检、白名单、执行及结构验证；迁移不调用 AWS、不修改云资源。新安装按既有现代迁移流程创建共享表。

卡片和编辑框均提供“移除配置”，失败状态不再禁用移除。确认会放弃面板的继续/恢复入口，只删除管理记录，保留 AWS 实例及新旧静态 IP，并展示已记录的静态 IP 名称供人工核对。失败操作默认允许修复名称和凭据；勾选“放弃未完成操作并解锁关联配置”后保存，才清空原操作进度并允许修改区域、实例或关联服务。正在排队或执行的任务仍禁止编辑和移除，失败记录也需取得实例操作锁才能修改，避免与未退出的 worker 并发。

## 原生路由管理

新建仅使用 sing-box 原生配置，已有 V2Box 兼容规则保留编辑入口。模板支持域名/IP 阻断、代理出口、typed HTTPS DNS 和远程 HTTPS 规则集；切换模板会替换 JSON，保存前需修改示例参数。列表显示路由/DNS/出口/规则集摘要与主服务引用数量。节点选择时统一合并并检查标签引用，已被引用的规则不可直接删除。

## 域名启用进度与后续操作（2026-10-23）

域名页先显示“保存域名 → IP 上报 → 解析同步 → 启用域名”进度、当前生效域名、目标域名与下一步。已保存的编辑表单默认折叠，避免将再次保存误认为启用。IPv4/IPv6 按选择的地址族检查最近十五分钟上报；解析成功时间也需新鲜。解析就绪时突出启用操作，双栈缺少任一上报、停用、归属冲突、凭据问题、旧节点能力不足、验证中与失败时分别给出后续操作。

普通 TLS 节点缺少 certificate-transition-v1 时提示升级至 v1.0.5，并可直接查看升级命令；Reality 不受此证书能力限制。能力提示复用一次 Cache::many 批量读取，不访问 Cloudflare、不增加逐节点数据库查询。后台仍独立验证启用条件，界面判断不替代服务端校验。

只有面板确认启用后，published_domain 才改变。抽屉轮询观察到实际发布时刷新节点列表；关闭抽屉也刷新一次。已生效时提示客户端更新订阅，隐藏重复启用操作。没有提前修改节点 host、绕过证书验证或将“解析已同步”视为客户端地址已切换。

## 部署命令入口整理（2026-10-23）

后台不再提供下载 node-network.py 后仅执行 ip 的查询命令；此命令只在终端显示地址，容易与自动上报配置混淆。节点侧诊断能力保留。部署页按新节点安装、已有节点升级和自动 IP 上报说明用途；“管理域名与 IP 上报”跳转现有域名页，统一使用“配置 / 修复 IP 上报”，不再展示第二套上报命令。部署统一使用 V2Box 安装、升级与运维入口。

上报弹窗明确说明将公网 IP 定时提交到面板以更新域名解析。域名页未收到上报时直接引导使用本页配置入口，不再要求 V2Box 管理员跳转其他页面。入口跳转只加载既有状态，不生成授权或更换密钥。

## 已有节点配置与修复 IP 上报（2026-10-23）

V2Box 的“部署与接入 → 域名与解析”和 Cloudflare DDNS 列表提供同一个“配置 / 修复 IP 上报”入口。保存并启用绑定后，生成一次性命令，在对应节点服务器以 root 执行；面板地址、节点编号及短期授权自动填写，不显示长期上报密钥，不重装或重启代理服务。

保留独立 node-network 服务：首次执行立即探测并上报，后续 systemd timer / OpenRC cron 每约五分钟运行；上报不依赖代理监听、TLS 证书或用户转发线程，因此新节点仍可先上报 IP、等待 DNS，再申请证书。新安装的一键部署继续自动配置；单独更新 V2Box 二进制不等于配置地址上报服务。

上报修复复用一次性部署授权存储与兑换接口，使用独立 latest-network 索引；授权有效十分钟，管理员权限/密码、节点配置、绑定及凭据快照变化会使其失效。生成命令不会更换现有上报密钥；服务器准备好依赖并兑换授权时才更换。网络用途授权不会返回节点接入密钥或证书部署权限，保留当前 IP、上报时间及 Cloudflare 退避状态。Cloudflare Token 继续仅保存在面板。

脚本先检查本机 /etc/v2box/config.json 的 NodeType、NodeID、ApiHost；不匹配、存在未完成的新节点部署或进程锁被占用时拒绝执行。上报设置失败时，权限 0600 的 /etc/node-network/enrollment-state.json 保留新上报凭据；重新执行同一命令从本机私有状态恢复，不重复消费短期授权。成功后删除恢复文件。若其凭据已被后续操作撤销，按脚本提示只移除该恢复文件，再生成新命令；不清除节点配置、证书或已运行的服务。兑换响应丢失且未落盘时需重新生成授权，不允许重复兑换。

上报辅助脚本统一跟随 v1.0.5 标签；独立 IP 上报本身不依赖新节点二进制，TLS 域名切换需要 v1.0.5 或更新版本。已有 IP 对应 DNS 不阻止上报，同名非托管记录的归属冲突需在后台核对后显式接管。

## 自动证书部署（2026-10-23）

新安装 V2Box 的一次性命令现在按“安装已发布二进制 → 兑换授权并保存私有恢复状态 → 配置 IP 上报 → 等待面板解析同步及公网 DNS 生效 → 启动证书申请 → 验证当前配置回执和证书 → 自动启用节点域名”执行。普通管理员手动切换及已有节点域名迁移仍保留原先的显式确认流程。

使用步骤：创建节点，TLS 证书模式选择 HTTP 申请（或已有独立验证凭据的 DNS 申请），保存托管域名，再复制部署命令到服务器执行。HTTP/DNS 模式下尚未填写 SNI 时，保存绑定会使用生成的域名补齐；已有证书名称不覆盖。HTTP 自动验证必须允许公网访问 TCP 80，且节点不能占用 80 作为业务监听端口；脚本检查本机 IPv4/IPv6 端口占用，不自动更改防火墙，也不能保证公网路径可达。仅有域名绑定不会把自签名或 Reality 改成 ACME。Cloudflare 域名管理 Token 仍不下发；DNS 证书验证沿用单独配置的凭据。

解析等待最多 15 分钟，复用原调度器创建记录，不在轮询接口请求 Cloudflare。对连接域名以及 HTTP 验证使用的独立证书域名，分别核对 Cloudflare、Google 两个公网递归解析器的 A/AAAA，所有结果必须与已上报的地址族完全一致；遗留 AAAA 或额外 A 记录不会忽略。外部解析器不可达、调度暂停、归属冲突、凭据故障等不会提前启动签发。公众 DNS 查询不携带面板凭据。

节点启动后最多等待 5 分钟：本次独立凭据必须已使用，当前配置须由节点确认应用；HTTP/DNS 证书还检查信任链、域名与至少一小时有效期。TCP TLS 协议进一步进行本地 TLS 握手；Hysteria/TUIC 的 UDP/QUIC 就绪依据证书检查和节点成功应用回执，不等同于真实客户端或公网 QUIC 连通性测试。完成接口再次检查绑定、IP 和配置，成功后才自动发布连接地址；重复完成可安全重试。

安装与恢复均有进程锁。进度及凭据存放在 /etc/v2box/deployment-state.json，权限 0600；失败保留，成功移除，临时上报密钥及时删除。可在同一目录运行 `sh install-v2box.sh --resume`；再次执行同节点的原命令也会恢复，不再次兑换已消费授权。恢复授权有效 24 小时，并受管理员权限/密码、节点凭据撤销及节点/绑定变更约束。已开始的证书流程不会被恢复脚本反复重启；若 CA 已拒绝或暂停，按节点日志和现有 ACME 保护说明修复后恢复，不自动删除保护状态或既有证书。授权过期或配置改变时停止，保留配置供管理员处理；不会自动覆盖已有节点配置或清空文件重新安装。

暂时的网络错误及后台繁忙有有限重试，授权撤销与配置冲突立即停止。新增 Python 标准库助手随面板 bootstrap 下发，安装入口自动补齐 Python、OpenSSL 与 flock；普通 TLS 部署还需节点上报已验证的证书指纹；需要升级含 `certificate-transition-v1` 的 V2Box 二进制并执行本轮 TLS 候选字段迁移，旧 v1.0.3 不具备该能力。

## Cloudflare 节点域名闭环

新增节点保存后直接打开“部署与接入 → 域名与解析”。先在节点管理的 Cloudflare DDNS 页登记并验证根域名，再选择根域名、自动生成或填写子域名前缀，选择 IPv4/IPv6/双栈。新安装 V2Box 的一次性部署命令自动配置独立 IP 上报；已有节点使用“配置节点上报”。Cloudflare Token 留在面板加密保存，节点只持有其绑定专用的上报密钥。

普通绑定同步成功标记“解析就绪”，管理员确认后才改变连接地址；新安装使用上方自动证书部署流程，在验证成功后自动启用。批量换根域名先预览旧、新域名映射，提交后等待同步，再逐节点或批量启用；未就绪、IP 已变化、节点地址被手动修改或证书配置不满足的节点不切换。普通 TLS 节点在启用时准备候选证书，验证并确认监听成功后同步连接地址、SNI 和证书域名。Reality SNI 与传输 Host 不做字符串替换；手动文件证书须覆盖新域名。迁移不保证已有客户端立即更新订阅。

旧托管解析切换后至少保留 24 小时；仍被节点连接地址、证书名称或绑定引用时继续保留。删除节点或解绑立即撤销上报权限，解析由原调度器异步清理，不阻塞删除接口。每次删除前重新读取记录、核对所属 Zone、记录 ID、名称、类型、归属标记及已知 IP；内容被外部修改时暂停并显示冲突。正在清理或仍有绑定的凭据不可删除，避免失去清理权限。

新建记录使用持久归属账本和 Cloudflare comment 标记。请求成功但响应丢失时，下轮可按标记恢复，不重复创建或误认他人记录。同名已有记录默认不覆盖；管理员可预览并明确接管没有其他归属备注的 DNS-only 公网地址记录。旧部署遗留且没有账本的记录只支持分页核查、逐条确认删除，预览有效 10 分钟；删除时再次核对完整记录。无法仅凭“未关联节点”判断一条记录确实无用，不批量删除网站、邮件等其他用途解析。

复用五分钟 IP 上报及每分钟调度，不增加用户请求或节点转发路径开销。正常每个绑定每五分钟每个地址族一次 Cloudflare 查询，仅 IP 或代理状态变化时写入；20 个 IPv4 节点约 5,760 次查询/天，双栈约 11,520 次，另计配置变更及清理。同步每轮候选最多 100 个，清理最多 10 个，设运行时间预算和请求超时，凭据限流采用退避。账本主要按节点与地址族增长；异常或被引用的历史记录保留供管理员处理。需正常运行 Laravel scheduler。

升级迁移 `2026_10_23_000001_manage_node_dns.php` 已加入 update.sh 白名单与执行顺序，新安装 SQL 同步包含表结构。安装入口固定 v1.0.5，包含证书切换能力；旧节点需执行升级命令。

## 节点访问目标统计的容量与保留

开关和保留时间在「日志与诊断 → 采集与保留策略 → 节点访问目标」，默认关闭；报表在「日志与诊断 → 节点访问目标」。报表展示估算缓存预算、累计接收字节和容量拒收批数；累计指标在连续空闲一小时后过期，不是滚动一小时账单或 Redis RSS。关闭不影响计费。统计采用五分钟时间桶，保留时间可选 1、6、12、24 小时；现有默认仍为 1 小时，日常排障建议 6 小时，跨天排障可选 24 小时。时间边界最多差一个桶。缩短时原子缩短旧桶 TTL 并清理超期数据，延长不会恢复已过期数据。去重窗口仍独立保持一小时。报表每批读取 12 个桶，聚合最多 6000 项；超限明确提示部分结果，可先按用户筛选。全局预算不随保留时间增加，容量不足可能拒收，不能保证完整保留窗口。

接收路径使用专用 Redis 缓存存储，不跟随应用的 file/array 缓存驱动。每批仅原子更新当前桶，不再搬运整小时状态；每桶最多 500 行，每节点最多保留 1,000 个一小时内批次 ID，全站估算准入预算默认 64 MiB（`TARGET_STATISTICS_CACHE_BUDGET_MB` 可设为 8–1024，更新配置缓存并重载进程后生效）、最多 4,096 个桶/批次容器。预算包含预估 Redis 对象开销，但不是进程硬内存上限；应通过 Redis 自身的 maxmemory 和监控控制物理内存。预算耗尽返回 429，不逐条淘汰去重信息，不回退写文件或数据库。过期预算索引分批回收，短时可能保守拒收。上报体不超过 256 KiB；按已认证节点限制每分钟 30 次，不按来源 IP 共用额度。

新节点可在「日志设置 → 节点访问目标统计」选择 30 秒、1 分钟、2 分钟或 5 分钟，默认 1 分钟，最多另加 10% 抖动。修改周期独立保存，不清空已有汇总或重新开启采集；开关和周期互不覆盖。策略刷新最多间隔约 60–66 秒，独立于上报周期；失败批次约 30–33 秒重试，避免长周期超过五分钟重试保留时间。旧节点忽略新字段、沿用固定周期，报表节点选项以“周期固定”区分；升级节点后报告 target-statistics-interval-v1 能力。租约最多 120 秒，配置响应的可选策略头减少独立轮询。关闭后面板立即拒收，节点同步或租约到期停采。UDP 每连接最多缓存 64 个地址，每节点最多 8,192 地址及 1,024 个持有缓存的连接；TCP 只缓存一个固定目标。达到容量时可丢失统计，计费保持独立。

默认 Redis 连接沿用现有缓存主机和库；可通过 `TARGET_STATISTICS_REDIS_URL`、`TARGET_STATISTICS_REDIS_DB` 指向独立实例。若要求目标信息只存在于短期内存，应在独立实例上关闭 RDB/AOF、限制访问并排除备份；不要为了统计修改共用 Redis 的队列或计费持久化策略。TTL 控制在线数据有效期，无法擦除既有备份。升级后旧 v1 汇总不迁移，旧 Redis 项按原 TTL 过期；旧文件缓存与备份按原运维保留策略清理。节点优化需升级二进制，仅更新面板即可与旧节点兼容并使用新的接收存储。


## 部署与接入

常规部署只需一次性部署命令，不再展示重复的自动 IP 上报卡片。域名页仅在已存在节点缺少有效上报且没有待验证的域名切换时，在「高级维护」提供修复入口；新节点和上报正常的节点不展示修复命令。服务器上已有未完成部署时仍需按提示 `--resume`，脚本会拒绝另行配置上报。

「部署 → 运维命令与说明」集中展示更新、恢复部署、状态、日志和卸载命令。新版节点提供 `v2box update` 和 `v2box uninstall [--stop-network]`；卸载须在服务器确认，保留配置与证书，面板凭据及域名绑定需由管理员按实际情况清理。`--stop-network` 停用的是本机共享上报服务，其他服务仍依赖时不应使用。新命令与独立证书联系邮箱 `fastdog.ltd@gmail.com` 需要发布包含本次修改的节点包并升级后生效；不能将仅更新面板等同于节点功能已升级。

代理服务页通过「部署与接入」抽屉统一部署、域名与凭据管理；节点默认线路只提供接入设置，复用线路通过所属服务链接进入运维。新安装和已有节点升级分别显示，手动安装、IP 查询及 DDNS 引导收在折叠区域。

V2Box 新安装：生成一键部署命令、复制后在 Linux 节点以 root 执行。不需要在服务器再次粘贴长期密钥。命令包含十分钟内有效、仅可兑换一次的部署授权；生成新命令会作废旧命令，生成本身不改变正在使用的凭据。兑换时才生成独立密钥，并保留既有手动轮换的宽限/冲突保护。命令不存浏览器持久化存储，授权仅在 Redis 以哈希索引保留短期元数据；管理员权限/密码或节点凭据变化会阻止旧授权兑换。网络响应丢失时不重复返回密钥，需要重新生成授权并按凭据状态恢复。

部署脚本先完成固定 v1.0.5 正式安装包的下载校验，再兑换授权；授权从 --deploy-token 参数读取（兼容旧 stdin），通过私密 curl 配置文件送入 Authorization，不放入 URL 或长期密钥命令参数。配置使用同目录临时文件原子写入，权限 0600；临时凭据文件退出清理。已配置的节点会拒绝新安装流程，必须使用升级命令或 v2box credential；升级保留现有配置。

抽屉区分独立凭据是否认证与节点运行状态；检查接入状态仅验证当前有效密钥的最近认证，不把旧宽限密钥或认证请求当作节点运行正常。全局密钥迁移仍收在凭据管理的高级折叠项，不再要求重复输入管理员密码，保留管理员登录鉴权及操作确认保护。

V2Box 使用“wget 下载安装入口，再执行并传参”结构，长依赖检查移入面板提供的公开静态脚本。手动安装和升级命令为 wget 下载 install-v2box.sh 后由 sh 执行 --install；脚本自动安装 curl、bash、jq、unzip、coreutils 和 CA 证书，再转入正式 v1.0.5 安装器。sh 入口兼容最初未安装 bash 的机器。以 Linux root 执行，下载入口需先有支持 HTTPS 的 GNU wget，并能访问面板、系统软件源和 GitHub。一键授权部署通过 --deploy-token 传递一次性授权，脚本内部使用私有临时目录，仍不暴露长期密钥。

后台“生成一键部署命令”输出单行命令，包含面板地址和节点 ID，并通过 --deploy-token 自动传入十分钟一次性授权；复制执行即可自动写入独立密钥，不触发密钥输入提示。长期密钥不进入复制命令。脚本核对兑换结果与指定节点 ID，一旦不匹配即拒绝写入；原有 URL/授权双行 stdin 命令继续兼容。

后台复制格式为 `wget -q -O install-v2box.sh HTTPS_BOOTSTRAP_URL && sh install-v2box.sh --api-host HTTPS_PANEL --node-id ID --deploy-token ONE_USE_GRANT`。仅短期授权出现在命令参数；长期密钥仍只写入节点配置。

节点列表显隐只保留开关，移除重复文字操作。运行状态以可聚焦圆点按钮展示：在线绿、离线/额度受限红、无通信记录灰；保留状态无障碍名称及最近通信悬停说明，点击进入诊断。部署场景改为新安装/已有节点升级分段按钮，生成后突出复制命令；保留授权有效期、一次性说明及密钥轮换影响提示。

访问目标历史采用混合存储：Redis 原子接收/去重，`nodes:archive-targets` 每分钟归档已结束的五分钟快照到 `v2_node_target_snapshot`。每轮最多写 48 个桶、检查 96 个有效候选；SQL upsert 替换快照，不累加计数。成功写库后释放 Redis 桶和容量账本，批次去重独立保留。查询先读缓存再读同桶数据库快照，优先数据库，避免交接期间丢窗或重复计数。当前未结束时间桶仍实时查询缓存。

数据库汇总载荷预算默认 256 MiB（`TARGET_STATISTICS_DATABASE_BUDGET_MB` 可设 64–4096），最多 50000 个快照；预算不包含 SQL 索引、事务日志或磁盘分配开销。达到限制时暂停归档并保留缓存，报表显示容量状态；缓存继续受原有限额和 TTL 保护，不保证完整审计。每轮清理最多 1000 个超期快照，查询立即排除超期数据，物理清理可能有调度延迟。缩短保留期不会在随后延长时恢复已过期数据。需要正常运行 Laravel 调度器；长时间调度或数据库故障可能使未归档缓存过期。更新脚本已加入建表迁移，新安装 SQL 同步包含表结构。

### 近期详细聚合与节点日汇总

日志与诊断 → 节点访问目标分为“近期详细聚合”“节点日汇总”。近期数据仍按 1/6/12/24 小时保留，维持已有默认与设置；建议日常 6 小时。日汇总独立配置关闭/7/30 天，默认 7 天，总采集开关仍默认关闭。日汇总按 UTC 自然日保存，不含 userId、邮箱、来源 IP 或 URL 路径；用于节点级目标趋势，无法追溯单个用户 30 天访问历史。关闭采集后不新增数据，已有日汇总在保留期内可查。

每分钟归档，五分钟时间桶结束后额外等待五分钟，单轮最多 48 个桶、最多检查 96 个候选。快照和日汇总同一 SQL 事务提交，快照 daily_archived 标记避免提交后 Redis 删除失败重试导致重复累加；设置写入与归档使用同一互斥锁，避免保留期修改竞态。新功能只汇总升级后归档的桶，不补算此前快照或已经删除的历史。

日汇总最多每节点每天 500 个不同目标，默认全局 200,000 行（TARGET_STATISTICS_DAILY_MAX_ROWS，可配置 1,000–1,000,000）。这是行数预算，不是数据库磁盘配额；索引、页分配、日志与备份另占空间。容量不足会拒绝新的目标并保留已接纳目标的累计值，显示不完整标记；它不是精确全量 Top-N 排行。20 节点若每天各达到 500 个目标，30 天需 300,000 行，默认预算可能提前截断，应按实际日均目标数设置预算。每桶预取现有目标，再按 80 行批量 upsert，500 目标归档少于 15 条查询。

查询限制单节点和最多 30 天，按日期/流量/稳定 ID 排序，SQL 分页每页 25 行。页面显示实际最早日期、最后归档时间、行数预算与截断状态。缩短保留期立即使超期数据不可查询，物理清理每轮每表最多 1,000 行；再次延长不能恢复已过期数据。近期快照预算 256 MiB 与日汇总行数预算独立；快照空间不足或调度器故障仍会影响归档完整性。

新增迁移 `2026_10_21_000002_create_node_target_daily.php` 已列入 update.sh 白名单和执行列表；新安装 SQL 同步建表。无需更改 V2Box 上报协议或发布节点二进制。

### 30 天日汇总性能与清理

日汇总查询先读取单节点最多 30 条日元数据，计算总数与目标页日期窗口，再用节点/日期索引读取 25 条目标。整天通过元数据跳过，SQL OFFSET 不超过 499；日期、流量和 ID 都倒序，使用已有索引反向扫描，避免混合排序产生 filesort。全局行数只用于容量展示，缓存 60 秒，归档会刷新此值；归档准入仍在互斥锁内读取精确行数。

日汇总清理按 expires_at 索引分批删除，每轮每表最多 1,000 行。缩短保留期与持久清理游标在同一事务保存；保存不再同步重写全部历史，每分钟最多更新 5,000 行的过期时间。查询立即按新天数过滤；后台改写完成前禁止扩大保留期，避免尚未改写的旧数据重新可见。后台可检查清理进度。游标和每批更新在同一事务中提交，重启后继续执行。需要调度器持续运行。30 万行最坏约需 60 轮改写；物理删除可能更晚完成，设置不可理解为立即擦除磁盘数据。

20 节点 × 500 目标/天 × 30 天 = 300,000 行；默认 200,000 行预算不自动扩容，若要覆盖这一上限可设置 TARGET_STATISTICS_DAILY_MAX_ROWS=400000 并预留索引、日志和备份空间。达到上限仍会截断，不能保证全量访问历史。

列表概况调整为全部节点、异常节点、维护中、额度受限；增加异常/维护筛选和管理状态列。名称及运行圆点共用详情抽屉，部署与接入入口仍保留。详情复用部署卡片和共享抽屉边距，不新增顶层导航或高频后台轮询。

维护模式与配置应用回执的权限、服务关联、到期和告警语义见 [运行诊断](admin-diagnostics.md#节点维护与异常管理)。维护保存失败保留表单、阻止重复提交；关闭抽屉或离开页面前保护未保存内容。维护隐藏仅影响后续获取的订阅和节点列表，不保证已有客户端立即更新。


### 托管 TLS 域名验证

“验证并启用域名”先准备候选证书，普通 TLS 的连接域名、SNI、证书身份在节点验证和监听启动确认后同步发布；Reality 的 SNI 不变。绑定卡片及域名管理列表展示验证中、切换未完成和已同步状态，验证中阻止重复启用，失败保留原地址并可重试。证书模式、失败恢复、升级依赖与连接中断边界见 [V2Box 验证切换](v2box.md#托管域名与-tls-验证切换)。

### Cloudflare 拦截部署恢复请求

部署恢复返回 403 且说明因 browser's signature 阻止访问时，请先检查 Cloudflare 安全事件与 Ray ID；这不代表面板已撤销部署授权。部署助手使用明确的 `v2box-deployment` User-Agent，但客户端标识不能替代鉴权，也不能保证通过浏览器防护。

若命中 Browser Integrity Check，可创建仅针对面板部署进度接口的自定义 Skip 规则，选择跳过 **Browser Integrity Check**，保留其他 WAF、限速和面板鉴权。将下面的主机名替换为实际面板主机：

```text
(http.host eq "panel.example.com" and http.request.method eq "POST" and http.request.uri.path eq "/api/v10/server/enrollments/progress")
```

参考 [Cloudflare Browser Integrity Check](https://developers.cloudflare.com/waf/tools/browser-integrity-check/)。仍被拦截时按安全事件确认具体规则，不扩大为全站跳过防护。规则修正后，从面板重新下载 bootstrap，再执行 `sh install-v2box.sh --resume`；保留原部署状态和证书，不需要重新兑换授权或更新节点二进制。实际授权过期、撤销或节点配置冲突仍会停止部署，需按对应面板错误处理。


### 默认线路的直连、中转与共享入口

维护入口为“节点管理 → 服务器与域名”。服务器与域名分开维护。服务器记录代表实际机器；一台机器的上报凭据可更新其关联的多个域名，但不能选择其他服务器或任意域名。升级为每条旧绑定创建独立服务器记录，保留原 IP 和上报凭据，不按相同 IP 自动合并。确认实际共用机器后，可在节点绑定中选择同一服务器。

- **直连**：连接域名解析到节点服务器；普通 TLS 的 SNI 与证书身份跟随连接域名。
- **四层中转**：入口域名解析到中转服务器，回源域名解析到节点服务器；连接端口和节点监听端口独立。TLS 在 V2Box 终止，证书覆盖入口域名。Reality 的 SNI 仍独立。
- **共享入口**：先在“服务器与共享入口”添加入口服务器与域名，再由节点引用。同一入口服务器的同一端口只分配给一个节点，包含不同入口域名之间的冲突检查；此版本不支持同端口的 SNI 分流。删除单个节点保留共享入口；存在引用时禁止删除入口或服务器。

部署顺序：

1. 维护 Cloudflare 根域名凭据，创建实际入口和节点服务器记录。
2. 为入口创建域名，复制“配置服务器上报”命令到入口机执行。该命令只配置 IP 上报，不安装、重启或更换 V2Box 密钥。授权一次有效，10 分钟过期；失败可按原命令恢复私密本地状态。
3. 在节点的“域名与解析”选择中转方式、回源服务器、共享入口和入口端口，维护回源子域名。现有同名 Cloudflare 记录需预览并明确接管。
4. 普通 TLS 中转的自动证书使用 DNS 验证；在节点 TLS 设置单独填写 DNS 提供商及受限验证凭据。面板管理 Cloudflare 的 Token 不会作为节点部署凭据下发。已签发的文件证书也可使用；HTTP 验证不用于四层中转。
5. 在节点机执行一键部署。助手先上报回源 IP，分别等待入口及回源解析，再申请证书、验证证书和节点监听。已有节点使用“验证并启用域名”，候选失败保留原配置，成功回执后才发布连接域名、端口和普通 TLS 身份。
6. 在入口机应用“入口转发配置”片段。需要 Nginx 1.27.3+ 和 stream 模块；放入现有 stream 上下文，替换该节点原有片段，先 `nginx -t` 再重载。生成器按协议提供 TCP、UDP 或两者，使用带共享 zone 的 `resolve` 回源，避免 Nginx 启动时解析一次后长期缓存旧 IP。根据实际环境检查防火墙和 DNS 解析器可达性。
7. 通过入口实际连接客户端，再点击“确认转发测试完成”。该状态是管理员确认，面板不会把节点本机就绪冒充端到端转发测试，也不会自动登录或覆盖入口服务器的 Nginx 配置。入口或回源 IP 变化后清除旧确认。

更换回源域名会保留“已确认回源”的旧解析，直到管理员更新转发配置并确认测试完成，再进入至少 24 小时的清理宽限期。正在使用的共享入口更换根域名时，新建目标入口，再逐个节点验证切换，最后删除无引用的旧入口。中转切回直连会恢复节点监听端口，避免订阅继续使用中转端口。

停用服务器会阻止其 IP 上报与 DNS 同步；重新启用后，应在该服务器执行生成的上报命令恢复被拒绝后暂停的本地上报任务。编辑服务器中的“重置上报凭据”会立即撤销旧凭据并提供新的一次性配置命令；原解析保留，同机其他域名需一起使用新的上报配置。正常新增同机节点复用服务器上报凭据，不轮换导致其他节点失效。

Nginx 动态解析版本要求参见 [官方 upstream 文档](https://nginx.org/en/docs/stream/ngx_stream_upstream_module.html#server)。生成配置不启用 PROXY protocol；节点通常看到中转机来源地址，原客户端 IP 透传需要额外设计，不由此流程自动开启。


### 代理服务与多入口接入线路

节点管理统一使用“接入线路、代理服务、入口转发、服务器与域名”。服务器表示实际机器，IP 上报只更新该机器负责的域名；代理服务持有协议、监听端口、用户和 TLS 配置；接入线路持有订阅名称、权限、展示信息和连接地址。原独立节点保留默认线路及订阅 ID，原关联节点迁移为服务关联，不再使用父子节点称谓。

新增线路先选择代理服务，再选择直连或共享入口。一个服务可同时提供直连及多个入口线路，一个入口服务器可通过不同监听端口连接多个服务。同一入口服务器端口不能重复分配，不提供同端口 SNI 分流。线路权限组必须是服务权限组的子集；服务、入口和服务器仍被已发布线路或草稿引用时禁止删除或更换归属。

普通 TLS 的证书及 SNI 属于代理服务，关联线路的连接域名可以不同，不随每条入口线路切换。Reality 身份独立。旧默认线路仍沿用上节的候选证书验证与地址切换流程。中转服务使用 DNS 验证或已有证书，不能依靠四层转发完成 HTTP 验证。Cloudflare 管理 Token 不通过订阅下发。

编辑抽屉展示客户端、入口、回源服务器及代理服务的简易拓扑，修改后显示“待保存预览”。保存只写入草稿；新线路保持隐藏，既有线路保留当前发布地址及展示信息。管理员应用生成的 Nginx stream 片段、执行语法检查并完成实际客户端连接测试后，勾选确认再发布。发布再次核验版本、配置摘要、DNS、服务在线状态及配置应用回执。此流程不自动登录入口服务器、不自动修改 Nginx，也不宣称已经进行端到端探测。

入口转发页集中列出已保存入口和当前发布路径；旧端口与候选端口在切换前同时保留冲突保护。已发布回源及入口域名保留清理引用。状态检查由管理员操作触发，拓扑不新增轮询；订阅配置使用服务信息批量合并，不为每条线路执行额外数据库查询。接入线路配置上限为 2,000 条，防止管理侧引用与冲突检查无界增长。

升级迁移保留 ID、地址、排序、权限及名称，先检查旧关联的协议、TLS 身份、层级和权限一致性，异常时指出表及记录 ID 并停止，避免静默改写。迁移补齐 V2Box 的展示字段，删除旧 parent_id 列，关联线路的证书配置统一由服务读取。update.sh 已加入受控迁移；回退应恢复代码及数据库的协调备份。


### 安装恢复与操作含义

一键部署助手在恢复时先读取本机服务状态：已运行或正在启动时继续等待；服务停止或失败时，在本次恢复操作中尝试启动一次。不会重置 ACME 失败保护或删除证书。相同节点配置不再重复写盘，避免触发配置监听器重载，并保留自定义日志设置。等待就绪期间定期显示服务状态及剩余时间；服务已退出时立即提示查看日志，不再空等至超时。服务运行状态不等于配置或证书就绪，最终仍需面板回执和原有证书检查。

“刷新状态”只读取面板记录；“重试 DNS 同步”将任务安排到下一轮后台调度，使用已上报 IP 更新 Cloudflare；“验证并切换地址”才会执行证书/监听验证并发布地址。IP 上报缺失时不提供可执行的 DNS 重试，解析就绪时不显示冗余重试按钮。详情内保留折叠的操作说明，共享入口的重试也显示排队结果。

本次修复通过面板 bootstrap 内嵌助手交付，不需要更改节点二进制版本。服务器更新面板后，未完成的安装须重新下载后台提供的安装脚本，再运行其 --resume；只运行旧脚本仍会使用旧助手。实际运行服务卡住的其他原因仍应根据启动日志判断。

服务器列表移除“配置服务器上报”，编辑服务器内按需生成命令，直接显示在当前抽屉，不叠加弹窗。生成或重置授权不会关闭编辑器；未保存服务器变更时禁止生成或重置，变更后收起已有命令。重置保留确认，失败保留编辑器，关闭后清除命令；授权到期自动收起。新节点一键部署已经包含上报，独立中转服务器或上报异常才需要单独配置。

原“节点绑定”改为只读解析状态，纳入直连、回源与共享入口，显示服务器归属、解析和证书切换状态，提供统一配置入口指引。域名搜索及每页20条限制渲染量，服务器名称预建映射，移除该页原先额外读取完整节点列表的请求。日志按域名筛选，也可查询共享入口事件。无需数据库迁移或V2Box二进制更新。


### 直连与中转的一体化新增和操作指引

后台“新增节点与部署流程”按直连、中转分别提供完整步骤。新建代理服务的自动管理模式增加“接入方式”，可一次保存直连或入口中转。中转选择入口域名、入口端口，独立选择回源根域名、回源服务器和服务监听端口；无需先保存直连节点再修改域名绑定。首次回源部署可自动建立服务器记录，同机新增协议可复用服务器。普通 TLS 的身份在新增时使用连接入口域名，Reality 保留原有 SNI；切换已部署节点仍走原证书验证流程。

直连步骤：
1. 在“域名与解析”维护根域名、Zone ID 与 Cloudflare Token，验证通过。
2. “节点管理 → 新增节点 → 新建代理服务”，自动管理，接入方式直连；选择根域名、服务端口、协议和权限组。所属服务器可自动创建，也可选择已有的同机服务器。
3. 普通 TLS 选择 HTTP 或 DNS 申请；HTTP 需节点开放 TCP 80，DNS 需独立证书验证凭据。解析管理 Token 不自动作为 ACME 凭据。仅使用 IPv4 的服务器选 IPv4，避免等待不存在的 IPv6。
4. 保存后进入“部署与接入 → 部署”，生成并复制一键命令，在代理服务实际所在服务器以 root 执行。脚本配置 IP 上报、等待 Cloudflare DNS-only 解析、申请证书和验证监听。失败按终端提示恢复，不删除现有证书或部署状态。
5. 完成客户端连接测试后启用节点展示。

中转步骤（独立入口服务器、四层转发、TLS 在回源终止）：
1. 同样先维护 Cloudflare 根域名；入口和回源可以使用同一根域名的不同子域名。
2. 在“服务器管理”添加中转服务器，可选同时配置入口域名。已有服务器进入“详情 → 入口域名 → 添加入口域名”，可继续添加多个入口，无须重建服务器。
3. 编辑入口服务器，在“服务器 IP 上报”生成命令并在入口机器执行；等待入口域名解析正常。此命令只配置上报，不安装 V2Box 或 Nginx 转发。
4. “新增节点 → 新建代理服务 → 自动管理 → 入口中转”，选择已配置的入口域名和入口端口，再填回源根域名、独立回源服务器及监听端口。普通 TLS 自动申请用 DNS 验证并填写独立验证凭据；证书和 SNI 覆盖入口域名，证书部署在回源；Reality 的 SNI 保持独立。
5. 保存后在“部署与接入 → 部署”复制一键部署命令，只在运行代理服务的回源机器执行。脚本等待入口与回源解析就绪，完成回源证书和运行状态验证。
6. 在节点“域名与解析 → 入口转发配置”复制 Nginx stream 片段，合并到入口机器配置。需要 Nginx 1.27.3+ 及 stream 模块；先执行 nginx -t，通过再重载，开放对应 TCP/UDP 和回源监听端口。面板不通过 SSH 自动安装或修改 Nginx。
7. 用客户端从入口实际连接；无需在面板确认测试完成。回源就绪不等于入口转发已连通。更换回源后，旧解析默认保留，需要清理时进入“高级维护：旧回源解析”预览并确认延迟清理。
8. 多入口共用已有服务，仍使用“新增节点”，选择“复用已有服务”。线路沿用服务原有 TLS 身份和运行进程，保存、检查转发和连接后“确认并发布线路”，不重复部署 V2Box。

功能归属：服务器详情管理入口域名和上报，新增只读“本机入口转发”汇总；节点接入维护入口端口与代理服务对应关系，复制配置并验证/发布。服务器汇总复用现有 DNS 响应，不新增后台请求，保留待发布和当前发布入口的双重归属；中转切为直连时，旧入口在完成切换前继续可见。转发总览的默认服务操作直接打开域名与接入配置；节点配置已应用的中转服务显示“代理服务运行正常”，另行提示通过入口进行客户端测试，不要求点击测试确认。不在两个页面重复维护转发参数。

后端复用原有创建事务、DNS 生命周期锁和端口/证书检查，新增部署参数仅允许入口标识与端口。重复端口、入口停用、入口与回源同机、证书模式不符及非法入口都会拒绝，失败整体回滚。无需数据库迁移或V2Box协议变更。


### 统一节点管理

节点管理只保留一个节点列表，不再提供独立的代理服务列表或旧页面跳转。列表维护展示与排序，集中呈现连接地址、权限、倍率和运行状态；复制与删除收进“更多操作”。存在复用线路时禁止删除对应独立节点，后端引用保护继续生效。

点击“编辑”后分为线路信息、服务配置、部署三个部分。默认线路维护名称、权限、倍率和展示信息；复用线路继续保存待发布配置、检查连接并发布。服务配置仅维护协议、监听、TLS、路由等技术参数；部署负责域名与解析、命令、凭据和运行验证。复用线路的后两部分定位到所属服务，并提示会影响同一服务的全部线路，不为每条线路重复部署。切换部分或关闭时检查未保存内容，保存中禁止切换。

底层保留现有服务复用结构，不新增数据库表或迁移线路。计费倍率仍由共享服务统一计算；默认线路修改倍率会提示关联影响，不提供无法准确区分流量的独立线路倍率。默认权限组作为服务认证范围，移除仍被已发布线路或待发布草稿使用的权限组时拒绝保存。

默认线路通过专用 GET/PATCH 接口仅读写名称、权限、倍率与展示信息，带版本校验和事务锁。服务技术保存与内核转换保留数据库中的最新线路字段，旧编辑器也不能覆盖已更新的名称、连接地址、展示或排序。协议、证书和监听字段注入线路接口会被拒绝；管理员会话、CSRF、来源校验与精确跨域预检保持生效。

统一列表保留节点显示偏好。服务定位使用 `#/nodes?service=内核:ID` 打开同一编辑界面的服务配置，不再打开第二个列表；不同内核的相同 ID 不混淆。仅打开需要的编辑部分时读取相应数据，列表复用已有节点响应建立关联映射。

### 新增与编辑字段一致性

新增独立节点按“线路信息 → 服务配置 → 部署”排列完整表单，编辑在同名部分维护。新增需要一次保存线路、服务与域名配置以保持创建事务完整，保存成功后打开部署部分生成命令；编辑按部分保存，避免相互覆盖。线路名称、权限、倍率、地区及展示字段共用 node-line-fields 定义；协议、监听、TLS 和路由共用技术字段排序。

统一使用“节点名称”“计费倍率”“监听端口”“节点服务器”“地址类型”“子域名前缀”等名称。监听端口属于服务配置；手动连接地址和连接端口属于部署；中转入口端口独立保留，不能误认为监听端口。复用节点的新增与编辑均通过原接入线路编辑器，名称标签保持一致，并显示共享倍率；保留待发布、检查和发布流程。继续沿用现有表结构。

### 新增、编辑与部署的完整对应关系

| 新增配置 | 保存后的维护位置 |
| --- | --- |
| 名称、权限、倍率、地区、城市、后缀、标签 | 编辑 → 线路信息；复用线路倍率随所复用服务的默认线路设置 |
| 内核、协议、监听、传输、路由、限速与协议扩展 | 编辑 → 服务配置；内核转换需要核对路由并重新部署 |
| 证书模式、验证凭据、文件路径及手动 / Reality SNI | 编辑 → 服务配置 |
| 托管普通 TLS 身份 | 服务配置显示当前值，部署 → 域名与解析变更；证书及节点验证成功后发布 |
| 手动连接地址和端口 | 部署 → 域名与解析 → 手动连接地址；版本校验并明确确认后保存 |
| 自动管理方式、根域名、前缀、地址类型、节点服务器、直连 / 中转、入口与入口端口 | 部署 → 域名与解析 → 修改域名设置 |
| 展示与排序 | 节点列表的开关及排序操作，不重复放入服务配置 |

独立节点保存后直接进入部署，不要求再次填写已经保存的域名；手动节点也不强制进入根域名表单。复用节点第一次保存后进入正式线路编辑器，保留服务器端草稿及版本，继续检查、配置转发并发布，不签发额外安装授权。新建草稿显示“尚未发布”；已有线路第一次保存草稿会记录原生效端点，原地址保持可见且不会提前切换。

手动地址接口仅接受 host、port、节点标识、版本和确认值，不接受协议、监听、TLS 或凭据字段；版本覆盖相关连接和技术配置。托管绑定及复用线路不能绕过各自验证 / 发布流程。新建手动地址时，前端提前提示自动 ACME 需要托管域名；服务配置保留证书参数和 Reality 独立身份，托管普通 TLS 的 SNI 不能在技术保存时绕过域名验证改写。

托管直连节点可“改为手动维护”：保留当前生效解析、端点、证书、物理服务器和额度关联，仅暂停 DNS 自动更新。仍有复用线路 / 草稿、正在验证证书，或尚未从中转完成直连切换时禁止操作。手动维护通过现有绑定的状态保存，不增加表或列；独立服务器 IP 上报继续工作并在列表显示。重新设置自动域名时预填原服务器、根域名及前缀，复用同一绑定，解析和证书验证前不改生效端点。手动或未启用的来源服务不能生成无法发布的复用草稿。

相同配置重复保存是幂等操作，不重置解析、证书候选或转发确认。域名编辑版本只包含配置字段，IP / 状态轮询不会改变版本；另一个管理员更改域名时，保留本地输入并拒绝旧版本写入，可明确放弃后重新载入。离开编辑、切换部分及新建线路中跳往服务器管理均保护未保存数据。

托管直连监听端口修改后，界面进入地址验证步骤。非 TLS 节点须在线并确认新配置，普通 TLS 继续验证证书 / 监听后发布，随后同步默认连接端口；显式配置不同端口的已有别名保留，复用线路分别检查后发布。没有完成发布的初始化域名不再仅凭名称相同而显示成功，新节点也不会被误导去执行升级。

新增和编辑共用的元数据输入增加现有存储容量校验，超长标签、权限数组和倍率精度返回可修正的验证错误，不落入数据库保存异常。所有新增读写仅属于管理端；没有数据库迁移、节点协议或 V2Box 二进制变化。

新增流程与服务器入口转发分工：常规新增默认独立部署，直接选择直连或入口中转；“为现有节点添加连接线路”置于高级选项，只有多线路共用监听、证书和倍率时使用。服务器新增提供用途预设，中转用途同时配置入口域名；服务器列表、编辑和详情依据实际服务与入口关联显示代理、中转或混合用途，不另外保存可能与实际关联冲突的角色标记。尚无关联的服务器显示待配置用途。

入口转发标签归入服务器管理。单机详情的“本机入口转发”按已保存和当前发布路径汇总，可直接打开对应节点的接入配置或共享线路编辑器；沿用相同的保存、证书验证、连接测试和发布动作，不建立第二套规则。节点新增/编辑保留入口与端口选择。入口只上报 IP 不会自动安装 Nginx，转发片段需在入口服务器检查并加载，随后完成真实客户端测试。打开配置仅按需读取节点与权限组，不生成部署授权或触发安装。

节点编辑统一分为“节点信息、接入路径、代理服务、部署与诊断”。共用代理服务的订阅节点保留独立名称、国家地区、城市与标签；新增共享线路可以默认带入出口地区，手动修改后不随服务选择覆盖。地区代表出口，入口位置由接入路径表达。编辑顶部列出同一服务的全部关联节点，协议、监听、证书和部署的影响范围适用于默认节点及所有关联节点。

节点信息与接入路径切换沿用未保存确认；共享节点两种编辑视图保留完整已保存关系，隐藏另一组字段不清空其值。独立节点的接入路径直接定位域名设置，部署视图独立初始化，避免切换后停留在错误页签。入口转发汇总打开接入路径，而非节点展示信息。计费倍率继续受服务级上报约束，不新增未经流量归属验证的按入口计费。

迭代清理：移除无调用方的 _domainOnly 标记与列表别名；节点列表明确指定编辑分组，不再回退到混合表单。统一服务选择的权限组和出口地区初始化逻辑，复用关联节点计算，避免共享服务切换时两套行为漂移。手动清空地区和取消服务选择继续保留独立名称。

服务器统一管理入口：列表和服务器名称均打开同一管理抽屉，移除并列编辑、详情及相互跳转；删除服务器收进更多操作。抽屉集中展示服务器用途、已保存 IP 和状态、基本配置、流量额度、上报配置、入口域名、转发、关联代理服务及有界用量记录。原详情弹窗替换为抽屉内的 ServerTrafficSummary，只在打开管理时读取最近90天用量；保存已有服务器不关闭抽屉，并刷新用量摘要。

服务器配置与入口草稿共用关闭和刷新保护；服务器未保存时禁用入口与转发操作，入口请求进行中阻止服务器请求。跨页进入节点管理前确认未保存修改。基础信息和额度沿用原子保存接口，不改变服务归属或清零用量；仅在周期、计费方向或额度调整至当前用量以下等相关变更时提示影响，单纯修改名称不触发额度确认。新增服务器仍可同一次请求创建入口。此轮无后端接口、迁移或依赖变化。


### 服务器上报状态与中转操作说明

服务器管理读取最新上报快照，不覆盖未保存的配置。仅在抽屉打开、页面可见且没有未保存配置或入口操作时每 15 秒刷新，关闭时释放定时器。列表区分未上报、双栈缺失、超过 15 分钟未上报及停用状态。中转入口未就绪时明确检查入口服务器，不再笼统提示同步回源解析。

接入方式使用“中转连接（入口转发至代理服务器）”，明确入口只转发 TCP/UDP，TLS 证书与加密连接由代理服务器处理。服务器管理提供配置顺序，额度字段折叠；节点四个编辑分区提供职责说明。独立入口仍需在本机执行上报命令，不能由另一台代理服务器代报。

复用 AdminDDNS、Nodes、ServerTrafficBudgets 测试，覆盖入口未就绪、最新快照保留草稿、双栈缺失、过期上报及定时器清理。未连接生产入口服务器，未执行实际 DNS 修改、证书申请或转发部署；界面修复不代表生产上报服务已恢复。


### 中转路径与证书配置引导

连接路径明确区分运行 V2Box 的代理服务器、客户端连接的入口域名和指向代理服务器的回源域名。普通 TLS 中转显示 DNS 证书配置顺序及 Cloudflare 参数说明，Reality 单独说明。证书参数独立显示在“TLS 与证书”分组。面板解析凭据仍不自动下发给节点，未改变权限或证书生命周期。Nodes 与 AdminDDNS 的 99 项检查通过；未进行真实 Cloudflare 授权或 ACME 签发。


节点路径配置优化：新增配置顺序统一为节点信息、代理服务、连接路径与域名；未绑定节点默认展开域名设置。普通 TLS 中转在保存前检查证书模式，明确返回代理服务的 TLS 与证书分区修改。DNS 凭据可能被脱敏，因此前端不以空凭据判断缺失，实际权限与凭据仍由后端校验。Reality 与无 TLS 保持原行为。复用 Nodes 与 AdminDDNS 测试覆盖字段顺序、去重和证书模式边界。


### 证书复用后台 Cloudflare 凭据

DNS 证书配置可显式选择已验证根域名的 Cloudflare 凭据。节点配置仅保存 dns_credential_id，选择后清除手动 dns_env；后台列表只读取凭据名称与根域名。节点配置下发时解析当前加密 Token，强制 cloudflare 提供商，检查域名范围、模式和凭据暂停状态；引用字段不会进入用户订阅。绑定与证书切换均检查目标域名，仍被证书引用的凭据禁止删除或更换 Zone。轮换 Token 后后续节点配置读取新值。

当前 V2Box 使用本机 ACME，因此选中的 Token 会通过认证后的节点配置接口交给代理服务器，无法在节点侧把一个宽权限 Token 限缩到单条记录；应使用限定相应区域的 Token。本轮不增加自动凭据选择，不把任意面板凭据交给节点，不新增数据库迁移或节点协议字段。测试复用 node-ddns 与前端既有测试模块；不调用真实 Cloudflare 或申请真实证书。

### 节点配置入口归位

节点编辑统一使用节点信息、连接与协议、部署与状态三组；连接域名与协议证书在同一配置页分别维护。节点部署内不再重复提供域名编辑标签，状态操作跳转至连接与协议。独立部署组件保留独立使用能力。

证书凭据按 TLS 身份域名匹配，中转以入口域名匹配，不能使用回源域名推断。新增过程中仅有一个匹配凭据且未填写手动凭据时预选；已有节点不自动改选。失效或不匹配的已有选择保留警示项，防止静默替换。最终权限与域名归属仍由后端验证。

证书选择在保存前校验当前域名归属与凭据可用性，直连／中转切换不会静默替换已有凭据。切回直连清理入口选择，直连服务器列表不受旧入口过滤。暂停的根域名不提供给新增流程。证书自动续期遇到权限或验证错误可能进入保护性暂停，需排除原因后恢复，不能以服务进程在线代替证书续期成功。

### 设置保存与实际生效

服务配置发生变化后清除上次下发记录，保留历史回执及最后成功时间；在节点重新拉取前，不再将旧回执显示为当前配置已应用。Cloudflare Token 更新后对引用该凭据的服务同样失效下发状态，按 100 条分批处理；不增加列表轮询查询。新配置只有匹配其摘要的应用回执才能确认。部署状态明确区分等待获取配置与当前配置无法下发。连接域名、入口转发和证书验证仍各有独立步骤，配置保存成功不代表入口转发已部署。


### 部署页一键检查

“部署与状态 → 部署检查 → 一键检查”执行只读公网检查，不重启节点、不申请证书、不修改 DNS 或 Nginx 配置，也不代替域名启用操作。展示配置回执、IP 上报、DNS、节点监听、在线证书、中转连接和续期验证边界；每项说明下一步。结果带检查时间和位置，设置或上报在检查过程中发生变化时，成功结果全部失效，要求重查。

DNS 使用固定 Google Public DNS HTTPS 查询 A/AAAA；托管域名核对服务器上报 IP。仅允许公网地址，任何混合私网/保留地址答案均拒绝；单个端点最多探测两条地址，逐条检查，不能用 IPv4 成功掩盖 IPv6 失败。连接固定到已核验 IP，禁用代理和重定向；只建立 TCP/TLS 连接，不向代理协议端口发送 HTTP 请求。每次查询最多 3 秒、每次连接最多 2.5 秒；管理员接口独立限制每分钟 4 次，并对同一节点加并发锁。结果禁止缓存，不包含凭据、私钥、底层异常文本。

普通 TCP TLS 服务验证信任链、身份域名及到期时间；中转需入口与回源的在线证书指纹一致才显示 TLS 连通性已验证，仍需客户端验证代理鉴权与数据传输。仅允许入口回源的防火墙可能使面板无法探测回源，此时显示待确认，不宣告节点故障。UDP/QUIC、Reality 和不支持的身份配置明确提示使用实际客户端，不以 TCP 成功代替协议验证。当前在线证书有效不等于自动续期已验证。本功能只更新面板，无需新增数据库迁移或更新 V2Box 通信协议。

### 连接、回源与 TLS 身份独立管理

中转连接地址取入口域名与入口端口，回源域名指向运行 V2Box 的代理服务器，TLS 身份在节点编辑的“连接与协议 → 协议与证书”中维护。新增托管节点未指定 TLS 身份时默认使用落地域名；已有节点切换中转入口或回到直连时保留落地证书身份与路径。默认直连域名更换仍可同步原先随连接域名使用的证书；显式独立身份不会被入口覆盖。Reality 保持独立。

证书 Cloudflare 凭据按 TLS 身份域名筛选和校验，允许入口、回源和证书分属不同根域名。域名解析凭据与证书签发凭据可以不同；Token 仍仅在受认证的节点配置中解析下发。Nginx stream 只转发 TCP/UDP，无需终止 TLS 或持有落地私钥。

修改已有托管 TLS 身份后，候选配置加密保存并下发 V2Box，订阅继续使用原身份。只有匹配候选配置摘要且带证书指纹的成功回执才发布新身份；失败、过期和并发变更不发布。此流程不改变连接地址、监听端口和 Reality 身份。独立身份使用现有 configuration-receipt-v1 回执，不把入口 DNS 地址误当作证书域名地址；无需新节点协议或数据库迁移。

一键检查分别连接入口与回源，以配置的 TLS 身份执行证书校验。订阅中的连接地址与 SNI 分别输出，不关闭证书验证。真实 Cloudflare 签发、续期和生产 Nginx 连通性仍需在实际部署后执行检查，本地回归不代表已验证这些外部环境。

### 节点与服务器管理界面层级

节点编辑保留“节点信息、连接与协议、部署与状态”三个分区，导航仅展示分区名称。集成编辑内取消第二层部署标签，节点凭据通过辅助入口进入并可返回；独立部署入口保留其原有导航。只在确有共用节点时显示影响范围说明。

连接分区显示地址与证书概览，部署页不再重复：连接地址始终显示当前发布地址，准备中的目标单列为待启用；回源地址与监听端口、TLS/Reality 身份各占独立区域。域名页先显示进度与下一步，再显示地址，IP 上报与时间记录折叠查看。新增摘要使用已有页面数据，不新增请求或轮询。

服务器统一使用宽抽屉，顶部可定位基本配置、IP 上报、入口与转发、用量与关联节点。定位仅滚动并转移焦点，不提交表单、不卸载编辑器，保留未保存内容；原有忙碌锁、修改确认、凭据过期处理继续生效。小屏导航双列、地址摘要单列。

### 部署解析等待与恢复

有效的一次性部署任务通过 POST 进度检查推进自身回源或入口域名的到期解析同步，每次最多同步一个域名；继续使用 DNS 生命周期锁和原有冷却、凭据暂停规则，不扫描其他节点。同步结果写入原有域名状态，后台重新读取即可看到，长期维护仍须运行面板定时任务。

安装输出区分入口/回源 IP 缺失或过期（IPv4/IPv6）、停用、Cloudflare 暂停或退避、公共 DNS 传播和独立 HTTP 证书域名检查；不变状态每四次轮询提示一次。错误仅输出受控原因，不回显任意服务端响应或凭据。更新面板后重新下载 bootstrap 并执行 --resume 可升级部署辅助脚本，无需更换节点二进制。

后台部署页提供“部署步骤与处理建议”，复用已有服务器、域名、凭据和节点回执数据，分别显示回源与入口上报/同步原因，以及配置、证书和监听确认。同步完成仅表示面板已同步，不等于公共 DNS 或客户端连接通过；真实公网结果继续由一键检查验证。未上报/过期、凭据暂停、限流退避和节点应用错误分别提供下一步。轮询保持 15 秒间隔，隐藏页面停止请求，15 分钟后暂停并允许手动恢复；不新增 API 或自动公网探测。

### 中转使用落地 HTTP 证书

中转配置允许 HTTP、DNS 或已有证书，不再因选择中转而强制将 HTTP 改为 DNS。HTTP 证书仍在代理服务器申请，TLS 身份默认保留回源域名，与客户端连接的入口域名独立。切换证书模式为 HTTP 时清除 Cloudflare 证书凭据引用。

自动部署要求证书域名的所有公网 A/AAAA 与回源上报 IP 匹配，公网 TCP 80 能到达代理服务器且未被其他服务占用，代理监听端口不能占用 80；续期时仍须保留这些条件。安装前校验公共解析和本地端口，证书申请结果及有效证书验证成功后才继续发布。公共 80 的最终可达性由 ACME 验证确定，本地端口空闲不代表外网可达。证书域名经入口的额外 HTTP 转发不作为此次自动部署支持路径，请改用 DNS 验证或将证书域名直指回源。无需修改 V2Box 二进制。

### 自动生效与人工边界

“连接与域名”保存后复用 `nodes:sync-ddns` 定时任务：同步解析，核对公共 DNS 和近期配置应用回执，再发布直连地址与端口。TLS 域名切换先下发候选配置，只有 V2Box 验证证书和监听并返回有效回执后才发布；失败保留原地址与证书，停止该次切换并允许管理员修复后重试。公共查询失败会重试，解析不匹配不会发布。检查期间配置或 IP 改变时丢弃结果。

共用服务的直连线路使用相同发布事务与版本校验。外部 Nginx 中转仍须人工确认实际转发；UDP 等无法从面板完成的连接验证保留确认入口。页面读取状态不触发写操作，正常直连不再要求重复点击检查和发布。编辑过程中暂停轮询回填，避免覆盖未保存内容。

依赖既有 Laravel 调度器持续运行。任务每分钟调度、DNS 按现有约五分钟同步节奏退避；每轮有时间预算，线路采用分批轮询，已生效配置不重复探测。不新增订阅请求中的网络查询。自动检查结果短期缓存且不包含凭据。

迭代遗留清理：节点列表移除旧版部署流程说明（其中入口 SNI 与证书凭据说明已过时）；前端移除不再挂载的手动一键检查组件与未调用的独立上报命令生成器。自动部署检查、节点端 DNS 异常信息、敏感配置保存确认、在线人数及最近流量上报列继续保留。

节点列表在线人数与最近流量上报每 60 秒通过轻量只读接口更新；页面隐藏、离线或打开编辑抽屉时暂停，失败按 120/240 秒退避，最长 300 秒，请求完成后才安排下一次，不并发轮询。轻量接口仅查询 V2Box 表的 ID 与服务关联，结果短缓存 5 秒供管理员共享，再按代理服务去重一次批量读取缓存，不读取用户明细、不探测节点、不生成部署配置。共享线路展示所属代理服务的总人数（不能按线路相加），在线人数沿用最近流量上报周期的活跃用户口径，超过五分钟未上报则显示未知，保留最后上报时间。

运行状态也随同一次轻量刷新更新，复用 `NodeRuntimeService::connection`：最近配置拉取或流量上报任一有效即可判为在线，两项均超过五分钟则离线；从未收到通信则显示暂无通信记录。共享线路使用所属代理服务的通信时间与状态，提示其不代表入口转发链路已验证。状态筛选和离线异常随刷新同步，已有额度限制提示保留；不增加轮询请求、缓存键或数据库查询。

节点编辑统一为“节点信息 / 连接与协议 / 部署与状态”三个入口。连接与协议将连接地址、域名、协议、监听与证书放在同一抽屉中，两个分区各自保存。两部分可连续编辑，提交期间暂时禁用另一分区，避免并发保存；域名变更不覆盖未保存的协议草稿。切换入口与关闭抽屉也检查两部分的未保存状态。协议保存后保留当前抽屉，域名发布后仅在协议草稿干净时更新服务配置。共享节点在同屏维护自身接入路径和所属服务参数，并保留关联节点影响提示。协议参数有未保存修改或正在提交时暂停连接区状态轮询，减少无效读取。

部署流程回归修复：共享线路自动发布切换所属代理服务后，合并配置页重新载入实际所属服务。若协议区有草稿则保留草稿并阻止向旧服务保存，需明确放弃后重新载入。资料刷新保留已挂载表单；共享接入状态读取使用完成后再安排的轮询，慢请求不叠加，错误延迟重试。

普通 TLS 关闭或改用 Reality 时，一键部署忽略残留的证书模式、域名及凭据，不再误检查 HTTP 证书端口或旧证书域名；普通 TLS 的 DNS、证书校验和失败保留规则继续生效。面板更新后新下载的 bootstrap 包含修复后的部署恢复 helper；已有暂停任务可重新下载面板脚本并执行 --resume，保留现有状态、配置和证书。

安装恢复：程序、管理脚本或 IP 上报组件缺失时先修复，再兑换部署授权。完整示例配置可由部署替换，真实配置仍受保护。更新和卸载的服务操作有超时限制；更新等待连续健康状态后确认，失败保留配置与证书，回滚失败保留备份并提示处理。

安装与更新入口同步至 V2Box v1.0.10，包含生命周期异常恢复修复。先运行 update.sh 更新面板，再使用后台命令进行新安装、恢复或升级；升级保留配置、证书及部署状态。

V2Box v1.0.13 安装与升级入口：一键新安装、缺失程序恢复、手动安装和升级固定使用包含证书热更新修复、多后台与局部重载能力的 v1.0.13；管理命令不指定版本时仍使用最新正式 Release。程序和配套脚本通过该版本 GitHub Release 分发，更新后台后可获取匹配入口。旧程序缺少能力时在兑换授权前停止，升级需安排维护窗口。

部署、手动安装和升级命令在生成时读取后台设置的节点 API 地址（server_api_url），为空时使用站点地址；末尾斜杠统一移除。保存地址后重新打开部署入口或刷新节点列表，复制新生成的命令即可使用新地址，不需要修改部署脚本。一次性部署授权绑定生成时的 API 地址，地址改变后旧授权拒绝兑换，应重新生成命令；此拒绝不会轮换现有节点密钥或修改证书、IP 上报绑定。升级命令只从新地址下载入口，不改写本机 Nodes、证书或既有上报目标。已有节点和 IP 上报继续使用本机原有地址；后台设置变更不会自动改写它们。

### 多后台一键追加与恢复

核心接入模式：同一服务器上的一个 V2Box 实例可以同时对接多个独立后台，后台可以使用不同数据库、不同管理员、不同站点域名及各自的节点和上报凭据。分别在每个后台创建节点并执行它生成的一键部署命令，按 `(ApiHost, NodeType, NodeID)` 追加 Nodes；不同后台即使节点 ID、用户 ID、服务器 ID 相同，也不合并身份或共享凭据。各后台无需共享数据库。各后台独立拉取配置、上报流量和 IP；一个后台离线、配置失败或封禁同 ID 用户不应影响其他后台。各代理服务需使用不同监听端口。


新版部署脚本对未使用托管 DNS 的节点也等待全新的配置应用回执，确认监听和配置已生效后才记录完成；端口冲突等应用失败时，仅撤回本次新增 Nodes 条目，保留其他后台、证书与上报配置。该检查通过脚本能力协商启用，旧脚本仍可沿用原响应；重新复制后台部署命令即可使用新版检查。非托管就绪授权不允许提交 DNS 验证状态或发布域名。

部署前分别探测磁盘程序、多目标上报脚本与当前运行进程的能力。已有进程缺少 multi-panel-v1/reload-signal-v1，或正在运行但程序文件缺失时，不自动替换二进制、重启服务或消耗部署授权。兼容实例通过 SIGHUP 请求逐节点重载，--watch=false 的服务也可应用追加。服务已停止时才启动，不用 restart 中断其他后台。

Nodes 在 IP 上报、DNS 及 HTTP 验证端口检查通过后原子追加。全新安装先把授权保留在私有恢复状态，不在检查前把节点放入活动配置，防止另一个后台部署时提前激活。重复身份被拒绝；已有节点的顺序、自定义证书路径、流量队列、落地页和全局设置不被覆盖。失败仅撤回本次新增且未被管理员修改的条目，保留其他后台和后续修改，也不删除证书、DNS 记录或上报目标。

恢复文件按后台与节点区分为 deployment-state-<摘要>.json，上报恢复文件同样按目标区分。旧单状态文件仍可读取；同时执行的安装命令由全局锁串行化。多个未完成任务时，通用 --resume 或 v2box resume 不猜测目标，应重新执行对应后台原部署命令恢复该条目。新授权只有成功兑换后才替换同一目标的旧状态，其他任务不受影响。

成功后保存权限 600 的完成回执，只包含授权哈希、节点身份与凭据指纹。再次执行相同的已完成节点部署命令，在本机配置及凭据仍匹配时不再次兑换一次性授权，也不改写 Nodes、证书或上报。节点凭据后来发生变化时，不用旧回执覆盖新配置。

IP 上报目标自动合并，服务器 ID 通过 --server-id 明确传入；不同后台同 ID 不混用。旧直接 Cloudflare DNS 目标、其他后台的凭据及退避状态保留。独立上报授权不安装或重启代理节点。所有恢复状态、快照和回执保持私有权限，临时授权及报告密钥文件在退出时清理。

### 部署故障模拟与恢复

部署验证复用现有脚本生命周期测试、后台 V2Box 工作流测试，以及两个独立数据库的 HTTPS 后台和已发布 v1.0.12 程序。覆盖以下场景：

| 阶段 | 模拟情况 | 预期处理 |
| --- | --- | --- |
| 前置条件 | 非 root、非 Linux、依赖齐全、apt/apk/dnf/yum、安装失败或部分安装 | 不满足条件立即退出；依赖齐全时不执行包管理器 |
| 安装与下载 | 新安装、缺少程序修复、下载中断、校验失败、损坏脚本、版本探测超时 | 不替换有效安装；失败保留原配置和证书，修复原因后重试 |
| 授权 | 过期、撤销、配置变更、身份不匹配、重复执行、兑换接口不可用 | 拒绝错误身份；可恢复任务保留私有状态；失效授权重新生成；已完成命令幂等 |
| 多后台追加 | 不同数据库同节点/用户/服务器 ID、第三后台失败、监听端口冲突 | 身份按后台隔离；只撤回失败追加；不重启其他后台服务 |
| DNS 与 IP 上报 | 单栈/双栈、中转入口、陈旧记录、解析不一致、解析服务不可用、上报鉴权和限流 | 校验失败不启动证书申请或发布域名；保留其他后台与直接 DNS 目标及退避状态 |
| 证书与启动 | HTTP 端口冲突、证书信任/域名错误、申请失败、服务启动失败、缓慢启动 | 不误报成功；保留证书和恢复状态；避免重复触发证书请求和全局重启 |
| 文件与并发 | 磁盘写满、状态文件写入失败、损坏 JSON、软链接、并发部署 | 原子写入或拒绝操作；失败不覆盖原配置；持锁任务不消耗第二份授权 |
| 就绪检查 | 后台断网、异常进度数据、回执缺失、完成响应丢失 | 有限重试/等待；不因网关错误误判撤销；保留状态，恢复后继续 |
| 升级与服务管理 | 运行或停止状态、systemd/OpenRC、重启失败、回退失败 | 原停止状态保留；升级失败回退；回退失败保留备份并提示人工恢复 |

真实进程联调验证脚本下载失败及授权兑换返回 503 后，同一份未消费命令可重试成功，原后台长连接、证书和 IP 上报配置均保留。普通非托管节点跳过托管 DNS 验证，但仍等待节点确认配置应用。异常进度响应的 `data` 必须是对象，否则最多重试三次，避免网关返回空值、数组或字符串引发未处理异常。

DNS、ACME、公共 IP、服务管理器和磁盘故障使用隔离夹具注入；不会向真实第三方申请证书或修改真实 DNS。测试不能替代目标服务器的公网端口、防火墙与系统差异检查。

### 新安装、重装、卸载与证书维护检查

新安装在配置了真实后台身份后启动；完整示例配置仍需兑换授权或填写真实配置，不以示例密钥启动。程序、配置或服务入口首次写入失败后可重试。重装保留已有 Nodes、操作员设置和证书；若部署尚未完成，则保留私有恢复状态并保持等待恢复，不重复启动申请证书。

卸载是整台服务器的 V2Box 实例操作，影响其全部后台条目；移除单个后台不应调用整机卸载。确认服务停止后才删除程序和服务入口。默认保留独立 IP 上报调度、配置、证书、ACME 账户和保护状态；显式 `--stop-network` 才停止本机共享上报。卸载不删除 DNS 记录、不远程撤销后台密钥。保留目录重装可复用原配置；程序已卸载时不能使用仅升级模式，应重新安装程序。

HTTP/DNS 自动证书由节点周期检查，未进入续期窗口不发起 ACME 请求；文件、远程和自签证书不由该任务自动续期。证书与私钥不完整时拒绝静默补发或覆盖。新证书在发布前检查配对、域名、有效期和信任；失败保留原证书及 ACME 限流/暂停状态。不要通过重装或删除保护文件反复触发签发。

真实 TLS 热更新回归新增同时更新证书和私钥、无效文件替换、恢复有效证书、多后台并存及旧代理连接持续传输。检查发现底层文件监听器会并发调用同一监听器的不同文件回调；节点源码以局部 fswatch 适配将其串行化，不阻塞其他监听器，并在 CI 中加入该依赖的回归测试。此修复需要发布并升级节点程序后才对既有节点生效；仅更新后台不会改变已安装的 v1.0.12 二进制。

全面复核补充：节点部署、仅 IP 上报部署及独立服务器上报授权在兑换时统一检查管理员注销标记，不能仅依赖封禁状态或密码变化；即使导入或修复数据中的其他字段暂未同步，注销后也不能签发新密钥。拒绝兑换不轮换已有节点或 IP 上报凭据。

### V2Box v1.0.13 发布与入口同步

v1.0.13 包含证书/私钥文件同时更新的回调竞争修复。后台一键部署、手动安装、程序修复、独立 IP 上报脚本和升级入口固定到该版本，旧版 v1.0.12 保留。原配置、证书和上报设置保留；升级运行中的共享实例会重启本机全部节点，应安排维护窗口，原停止状态保持停止。新版发布后，原节点需执行升级命令才能应用二进制修复。


### 中转测试提示与旧回源解析清理

部署就绪不再依赖人工转发确认，已移除确认按钮和 confirm-relay 接口。面板只声明节点配置已应用，不把人工点击当作链路探测。入口转发配置和实际客户端测试仍需完成；不修改线路的独立发布及证书验证流程。

更换回源域名后，旧托管解析默认保留，不因中转部署完成而自动删除。只有在“高级维护：旧回源解析”主动预览后，才可确认安排清理。预览列出旧域名、类型、IP 及处理原因；当前回源、节点地址、证书身份及其他绑定引用受到保护。提交使用十分钟有效的快照证明，记录或引用变化、预览过期及重复提交均拒绝。确认后仍保留 24 小时，后台删除前继续检查引用、记录身份和所有权；不重启节点、不修改证书和 IP 上报配置。没有旧解析时无需执行任何清理操作。


### 多后台共享协议端口（v1.0.14）

默认使用独立端口。新版节点支持多个独立后台以同一协议共享一个实际监听器：VLESS、VMess、Trojan、Shadowsocks（AEAD/2022）、Hysteria2、TUIC、AnyTLS、Naive。可在对应 Nodes 条目设置相同 SharedListener，或使用 `v2box share-listener public-443 1 2`。各后台用户编号可以相同，流量、在线状态、限速和配额独立；相同有效凭据（含 UUID 大小写和 SS2022 派生密钥冲突）拒绝更新。

部署命令默认自动判断同协议端口共享，无需追加参数；保留可选 `--shared-listener public-443` 用于显式指定组名。追加当前后台并保留既有配置及失败回滚流程。显式指定共享组时在兑换授权前检查 shared-listener-v1；自动匹配到共享候选时，在写入节点配置前检查已安装程序、运行程序与管理脚本的能力。组内协议、监听、TLS/Reality、传输、加密方式及服务端密钥、padding、路由等必须相同；普通 TLS 限文件或远程证书，文件证书外部统一维护，禁止多个 ACME 任务共写密钥。该功能不自动分流不同协议。

v1.0.14 已包含此能力；已部署 v1.0.13 的节点需升级二进制和管理脚本。初次合并监听应安排维护窗口；停止的服务保持停止。共享选择不修改其他节点字段、证书、密钥和 IP 上报；停用前需规划独立端口及证书路径。统一变更共享配置需先对齐各后台，再在维护窗口重启。


### v1.0.14 发布与入口同步

一键部署、手动安装、升级、程序修复与独立 IP 上报助手统一固定到 v1.0.14。安装/升级命令继续使用后台配置的节点 API 地址。升级保留已有 Nodes、自定义字段、证书、密钥、ACME 账户及保护状态和 IP 上报目标；不自动开启 SharedListener，不覆盖其他后台条目。运行中的实例整体重启，停止状态保持停止；首次启用共享需另行明确配置并安排维护窗口。升级失败按已有机制恢复旧程序，配置及证书保留。

一键追加同协议共享端口：直接执行第二个后台生成的普通部署命令，无需追加后缀或手工选择组名。端口不限于 443，脚本按端口、TCP/UDP 和监听地址识别冲突，兼容时复用已有共享组或生成稳定组名；不冲突的节点保持独立。脚本通过各自 HTTPS V10 API 核对新旧节点配置与用户凭据，自动将同端口的兼容旧节点和新增节点加入该组，不再需要先执行 `v2box share-listener` 或编辑 JSON。不同端口节点保留原设置；同端口配置冲突、凭据重复、面板不可达、旧版 API 或未完成证书切换时停止并保留原配置。普通 TLS 必须已配置相同的绝对证书/密钥路径或相同远程证书；脚本不会修改证书签发或续期方式。首次转换共享监听会自动重启一次本机 V2Box，所有活动连接短暂重连，应安排维护时间；加入既有共享组沿用 reload。新增节点启动失败或就绪超时会删除本次新增项，并只恢复本次修改的共享组；保留其他操作员设置，若共享组被人工改动则拒绝覆盖并保留私有备份。

自动证书共享要求 v1.0.15 及以上节点（包含 `shared-acme-v1`）：普通部署命令按需加入共享监听，HTTP/DNS 模式保持不变。同域名且续签配置一致时，只为新增节点生成固定域名的本地证书路径绑定，沿用原证书、私钥及旧 ACME 保护状态来源；原节点其他配置和 IP 上报目标不变。不同域名继续使用独立证书/私钥与续签任务，监听按 SNI 选择证书，客户端需要发送 SNI。不同证书域名禁止共写同一证书/密钥路径。HTTP-01 仍需要正确 DNS 与可用的公网 80 端口，节点协调多个续签操作而不抢占其他服务。相同证书的重复续签会在锁内跳过，续签保留旧私钥和权限；新证书验证失败保留原有效证书，其他后台继续运行。更新证书无需重启共享监听，首次转换为共享仍需一次重启。部署助手在配置发布前验证新程序能力，不会将旧版强行切换到不支持的模式。


### v1.0.16 管理脚本发布

管理命令修复统一包含在 v1.0.16 Release；面板的新装、升级及恢复下载入口固定引用该版本，不再内置管理脚本和安装器副本。已有节点执行 `v2box update` 或面板生成的升级命令后，才能获得新的 `status`、`log`、`deploy-status` 和 `deploy-log`。仅更新面板不会修改远程节点上已经安装的脚本。升级保留 Nodes、证书、密钥、IP 上报设置和原停止状态；运行中的服务会重启。
