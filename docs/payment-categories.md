# 支付类别、币种与网络

后台「支付配置 → 编辑」可选择常规支付或加密货币。加密货币渠道需填写币种、网络；内置常用图标，也支持自定义币种代码、网络代码、网络名称和网络图标链接。

例如两条 PaytaroQR 渠道分别配置 USDT / TRON 和 USDT / BNB Smart Chain，并各自填写服务商对应的支付方式 UUID。前台会合并展示为 USDT，展开后选择具体网络渠道。相同网络的多个渠道仍显示各自名称。支付类别只控制展示，不会在服务商侧自动开通币种或网络。

支付图标链接优先于默认币种图标，网络图标链接优先于默认网络图标。常规支付保留原图标选择器。所有内置图标本地托管，来源与许可证见 `public/payment-icons/SOURCES.md`。

分类保存在已有 `config._console_checkout`，无需数据库迁移。未配置的旧渠道默认常规支付，请手动为现有加密货币渠道补充分类。后台对配置进行服务端校验。

V10 支付方式资源新增 category、asset、assetIconUrl、network、networkName、networkIconUrl，始终只返回已启用渠道，绝不返回完整 config 或接口密钥。订单结算仍为 CNY 整数分，asset 仅表示付款币种；不改变服务商报价、签名、回调、订单 ID 或手续费计算。

前台选择多个网络的币种时先清空旧渠道选择，必须选择具体网络才可支付；仅一个可用渠道则自动选择。手续费和支付请求始终绑定渠道 ID，等待支付确认期间禁止切换。

验证：`php tests/payment-presentation.php`、`php tests/api-v10.php`，前端支付分类、网络选择、结算、V10 映射与支付开关测试，以及桌面和手机浏览器布局检查。浏览器测试使用模拟接口，未向真实支付服务商发起付款。
