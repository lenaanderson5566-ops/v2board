# 注册策略与前端联动

强制邀请开启后，仅支持发送至本人邮箱的邮件邀请，不提供邀请码输入。落地页显示“受邀注册”，登录页显示“了解注册方式”；未携带邀请链接的注册页说明获取方式，不显示注册表单。格式错误或缺少收件邮箱的链接被提前拦截。有效格式链接仍需后端核验：令牌、收件邮箱、有效期、是否已接受和邀请人状态；验证码检查不会消耗邀请，最终注册继续使用事务和锁保证一次接受。

邮箱后缀白名单开启后，注册页和发送邀请弹窗展示允许的域名，不支持的域名在发送验证码/邀请前提示。后台配置、页面启动配置及公共配置接口使用相同规范化：大小写、空格、开头 @、重复项、数组/逗号串/JSON 数组。域名必须完全匹配，不接受恶意前缀或额外子域。

两项限制只用于新注册及邮件邀请；已有用户登录和密码找回不受白名单、强制邀请和关闭注册影响。开启后需要刷新已打开页面以读取最新设置；后端始终按当前设置校验。无需数据库迁移。

新增页面文案覆盖当前八种语言。回归测试包括正常登录、两步注册、邀请收件人绑定、错误域名提前拦截、验证码优先队列调用与老用户密码找回。测试使用本地事务回滚和假队列，不发送真实邮件。
