# 面板安全复核与验收边界

本文维护已确认问题的修复约束、持续回归范围及部署待验事项，范围包括面板认证、会话、资源归属、资金、订阅、下载、内容渲染及锁定依赖。历史审计和历轮测试数量通过 Git 与原始日志查阅，不作为当前版本的通过证明。P1/P2 表示项目修复优先级，不是 CVSS 分数。

## 已确认问题与修复约束

| 优先级 | 问题与利用前提 | 修复及应保留的回归 |
| --- | --- | --- |
| P1 | 普通账户将佣金转入钱包时，内部流水曾再次调用 `setInvite`，产生上级返佣；需存在上级及适用策略。 | `UserActions::transfer` 不再计算返佣；`CheckCommission` 按固定内部标记、充值类型、零应付与无付款时间识别历史内部流水，只隔离未发放奖励。验证金额守恒、并发只成功一次及合法钱包支付/折抵返佣。 |
| P1，前提受限 | Passkey 登录先读 owner，重读凭据后曾未复核归属。攻击者需持有曾绑定目标、随后被撤销的私钥，并命中删除后重绑与旧登录的竞态；已有 MFA 仍需完成。 | 事务内要求锁定凭据的 `user_id` 与锁定账户一致。真实 ES256 签名夹具验证用户和管理员作用域的错误归属拒绝，保留签名、UV、RP、计数器及 MFA 校验。 |
| P1，需旧会话及旧密码 | 已认证改密请求曾可在密码恢复完成后用旧快照覆盖新密码。 | `changePassword` 先验证旧密码，再在事务内锁当前账户，复核密码哈希、算法、盐、邮箱及当前会话后写入，撤销全部会话。覆盖恢复或独立撤销发生在快照读取后的拒绝及正常改密。 |
| P2 | 开启注册邮箱验证时，注册成功次数限制曾不能阻止六位码错误猜测；涉及未注册邮箱归属证明。 | `RegistrationEmailVerification` 对规范化邮箱原子执行五次失败、300 秒预算；大小写、换 IP 与重发共享预算，429 返回等待时间，成功建号后消费验证码。密码恢复使用独立用途和预算。 |
| P2，依赖公告 | `symfony/mime` 8.1.7 命中 CVE-2026-45070；利用要求攻击者控制 MIME 参数名，未复现应用公开入口攻击。 | 锁定依赖保留 8.1.10 修复。独立安装核对反射加载来源，验证非法参数名拒绝与邮件业务；版本命中不能等同于应用远程可利用。[官方公告](https://symfony.com/cve-2026-45070) |

修前隔离验证曾分别证明额外返佣、重绑 Passkey 错登旧 owner、恢复后密码被旧请求覆盖，以及注册错码超出预算仍可继续验证。对应回归集中在既有 `commission-transfer-concurrency`、`mfa-api`、`auth-security`、`registration-policy`、`product-mail` 模块，不另建平行脚本。

历史内部流水只将未发放的异常奖励标为无效，保留原始返佣金额和归属供审计；不自动追回已发佣金，不改现有现金或佣金余额。线上历史损失、重复划转和异常订单须结合部署数据库另行核对，不能从测试夹具推断。正常钱包支付、权益折抵及零外部应付的真实订阅不能仅因金额为零被隔离。

## 持续回归范围

| 边界 | 必须保留的约束 | 说明入口 |
| --- | --- | --- |
| 邮箱与找回密码 | 精确邮箱身份及 IDNA 边界、验证码用途/账户状态绑定、过期与重放拒绝、并发单次消费、恢复后会话撤销；邮件仅发给账户已存邮箱。 | [认证安全](authentication-security.md) |
| 浏览器与原生会话 | 分作用域 HttpOnly Cookie、CSRF、精确 Origin、实时撤销与封禁检查；浏览器响应无 Bearer，原生保留自身协议；旧 localStorage 交换已退役。 | [浏览器会话](browser-sessions.md)、[MFA](mfa.md) |
| 权限和资源归属 | 无效/伪造凭据拒绝，订单、工单、会话与账户按所有者隔离，拒绝后记录不变；管理员用户信息显式投影，不返回密码材料。 | [V10 验证](api-v10/audit.md) |
| 退役与兼容入口 | 员工 API 返回 404，不恢复专用实现或角色字段；角色迁移不提升权限、不删除账户。旧管理入口拒绝 URL 凭据，兼容范围以保留清单为准。 | [保留接口](api-v10/retained-endpoints.md)、[升级流程](update-script.md) |
| 资金与回调 | 订单归属、渠道及不可变金额/币种快照、原始报文验签、到账事件、并发幂等和延迟回调；负价拒绝，合法零价保留。 | [多币种计费](billing-currencies-coupons.md)、[订单快照](order-payment-history.md) |
| 订阅与独立额度 | 恰好到期、耗尽、清理未运行、缓存及渲染中状态变化均检查；有效独立额度可在周期套餐到期后继续授权。公开安全提示不得携带真实凭据、模板或 provider，原生保留结构化错误。 | [订阅提示](subscription-info.md)、[独立额度](traffic-credits.md) |
| 节点与机器认证 | 节点密钥、订阅凭据和账户 JWT 是独立边界；普通账户 JWT 不能调用机器接口。配置先准备后切换，失败恢复及授权重放保护保持生效。 | [V2Box](v2box.md)、[节点管理](node-management-ui.md) |
| 文件与内容 | 下载归属、范围和大小限制；API 异常隐藏路径/堆栈，敏感响应 no-store；富文本过滤、危险链接及跟踪图片限制。工单只渲染文本，不解析图片或 HTML。 | [本地镜像](client-mirrors.md)、[邮件](product-mail.md) |
| Telegram 回调 | 机器人必须启用且令牌非空后才校验凭据；V10 使用请求头，保留入口使用原参数，不能以空配置生成可预测凭据。 | [Telegram](telegram-community.md) |
| 统计与日志 | 同意/GPC/DNT、严格事件字段、Origin、限流和保留期；不记录原始凭据、验证码、支付内容或配置正文，浏览器点击不作为付款证明。 | [监控与治理](observability-governance.md)、[日志管理](log-management-review.md) |

必要的授权输出仍按业务返回：原生登录返回本人的登录凭据，订阅配置包含本人连接凭据，管理员复制/CSV 可含受授权订阅链接，具备资格的下载账户接口返回共享账户信息，节点机器接口返回其服务用户的连接 UUID。字段白名单和鉴权不能替换为“所有接口均不返回凭据”的错误保证。

若未来增加工单附件，应另行实现格式白名单、解码重编码、大小/像素限制、随机名称、非执行存储和所有者鉴权，不直接接受 SVG/HTML 或仅信任后缀/MIME。当前工单关闭回归继续覆盖最后回复判断及事务行锁，避免调度旧快照覆盖用户新回复。

## 依赖与验证方法

依赖职责和锁定版本见 [项目结构](project-structure.md)。旧 Composer 审计例外 `PKSA-y2cr-5h3j-g3ys` 已移除；移除例外的静态断言不是漏洞审计。发布前应针对目标提交检查生产及全依赖公告和废弃包，并在独立安装树验证实际加载版本，不能只比较清单文字。

```sh
composer audit --locked --abandoned=fail --no-interaction
composer audit --locked --no-dev --abandoned=fail --no-interaction
cd frontend
npm audit --package-lock-only --ignore-scripts --audit-level=low --registry=https://registry.npmjs.org
npm audit --package-lock-only --omit=dev --ignore-scripts --audit-level=low --registry=https://registry.npmjs.org
```

审计时公告为零只代表当时工具和数据库的结果。升级 SDK 主版本需另核对协议，不能替换事件名或放宽金额检查来冒充兼容。开发与真实 `--no-dev` 安装的区别、执行范围及 CI 见 [测试组织](test-organization.md)。

## 部署仍需验收的事项

- 代码提交、推送或本地通过不代表生产已修复。按 [升级流程](update-script.md) 安装锁定依赖、发布配套 `public/console`、执行允许迁移并处理长驻进程；客户端、Helper 和节点的其他仓库需分别发布，面板更新不会替换其二进制。
- Web 根目录指向 `public`；生产关闭 debug，阻止 `.env`、`.git`、日志、备份和私有存储暴露，核验 ACL、数据库/Redis/节点管理端口、根密钥及可信代理。未完成 Git 历史秘密审计或线上云权限核验。
- 独立前端配置精确 Origin、正确站点/通知域及 HTTPS；核对 Cookie 同站条件、TLS 证书链和 CDN。敏感路径禁止缓存，订阅 URL 和服务器访问日志另行脱敏，不能只依赖应用数据库日志。
- 实际启用的支付渠道逐个核验签名、到账状态、金额/币种、商户归属、手续费与幂等。BTCPay 人工标记/部分支付、Coinbase 人工 resolved 等例外需核实到账后处理；历史跨币种待支付订单若无可信快照，不能猜测旧汇率，应复核或取消重建。模拟回调不证明结算、退款或净收入。
- 模拟 SMTP、AWS、Cloudflare、ACME 和服务管理不证明送达、云权限、IP 切换、DNS 传播或公网证书签发。生产 cron、午夜重置、队列/Horizon 重启和任务恢复需实际观察。
- 本地回环代理测试不证明真实节点配置已生效或已有连接何时断开。节点私网白名单会影响该节点用户；多后台单进程的更新/崩溃仍影响全部条目，不能当作主机故障隔离。Windows TUN/Helper、Android VPN、设备 Passkey 和应用内浏览器须对应平台验收。

这些边界不构成生产渗透测试或无漏洞保证。已修复的 Laravel 8 依赖、旧支付校验和旧认证方案不再列为当前未解决问题；启用渠道和部署配置仍须以实际环境为准。

## 证据与历史查阅

使用 `git log -- docs/security-review.md` 查询变更，再按提交查看原结论及对应实现和测试。原始日志、源码摘要、工具版本、失败与复测结果保存在忽略的 `storage/app/test-organization/` 或对应 Actions run；它们不随仓库分发，不应含凭据或生产数据。

当前验收报告绑定提交和锁文件，区分旧源复现、修后验证、未受影响基线、定向复验、跳过及环境错误；不能将不同快照的结果表述为最终源码全量重跑。浏览器和外部服务未执行的部分必须明确列出，见 [前后台验证](frontend-validation.md)。
