# 服务器流量统计与额度

入口：后台“节点管理 → 服务器流量”。创建代表实际服务器的额度，并绑定该服务器上的 V2Box 代理服务。关联线路自动沿用服务额度；同一服务不能属于两份额度。解绑不会清除已有服务器用量。

支持自然月（重置日 1）或每月指定结算日（1–28），按面板时区计算，日期区间左闭右开。统计本周期、本自然月及最近 30 个自然日。上传、下载是节点代理统计的方向，可选择仅上传、仅下载或合计。后台限额单位 GiB（1024³ 字节），0 不限额。

首次绑定导入节点现有的近期日统计与已接收但尚未入账的 V2Box 批次，不重复导入。原日统计已过期、丢失的数据无法还原。后续用量保存为服务器日累计，保留原始上传/下载字节，不乘用户流量倍率。重新保存或提高限额不清零用量；同一周期提高到当前用量之上、取消限额或进入新周期均能恢复服务。改变统计方向或结算日会重新计算对应周期。

V2Box V10 去重批次的接收记录与服务器用量在同一数据库事务提交，队列故障不会推迟服务器用量，重复批次不会重复计入额度。旧版 V2Box 通过原 StatServerJob 路径累计，保持原协议和原有重试语义。

达到额度后面板不再下发用户。新版 V2Box 还会共享同一进程内所有绑定节点的本地计数，在达限时拒绝新连接、终止已有连接；每次配置拉取周期同步服务器额度。管理员提高额度后，下一次同步会恢复准入和用户授权，无需重装节点。旧 V2Box 的限制和恢复依赖用户列表拉取。

V2Box 保留面板失败前的限制并继续累计本地用量，周期到期不会在面板离线时自行授予新的全服务器额度，联网后按新周期恢复。本地额度状态随拉取/上报周期保存到 TrafficSpoolDirectory 下的 quota-state；重载保留内存计数，进程重启读取已保存状态。尚未保存的计数可能在崩溃后丢失。

同一服务器运行多个独立进程时通过面板周期同步累计值，存在同步延迟，不能保证服务商账单意义上的严格零超额。已有连接的数据缓冲、协议开销、服务器其他进程流量也可能造成差异，应预留额度余量。统计不是网卡或服务商账单统计。

升级顺序：先更新面板并执行迁移、恢复队列/调度，再升级 V2Box，随后在后台绑定服务器额度。默认所有服务器未绑定，无限制。节点需要具备本地目录写权限。不要删除额度日累计、批次去重记录或 quota-state 来恢复服务；应修改限额。
