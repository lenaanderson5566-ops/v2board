# 用户体验优化核对记录

## 总览后续优化（2026-10-02）

参考用户提供的 Codex 截图，订阅卡与套餐额度卡采用白底圆角、轻边框、绿色剩余用量条；订阅卡保留唯一的一键导入与复制链接入口。连接详情仅保留链接查看、重置及节点列表，移除下载订阅。重复的已用流量／到期指标合并进对应卡片，余额保留为次要入口。

新增使用分析，提供本月和近 7 天切换、每日上传／下载堆叠柱图及明细链接。现有接口只返回本月数据，因此近 7 天亦限于本月已有日期；不虚构此前月份、周限额或精确重置时间。图表按原始上传／下载字节汇总，不乘计费倍率；套餐余量仍以账户实际用量计算。无记录时显示空状态。重置信息仅使用后端提供的剩余天数。

新增文案覆盖八种语言。生产构建、123 项前端测试通过（包含多记录同日聚合、月初范围、未来记录排除及负数处理）。桌面和 390 像素手机布局均检查；展开详情后导入／复制入口仍各一个，下载入口为零。

本轮以 React / TypeScript 用户前端为范围，保留管理员界面、现有业务接口、八种语言和自定义页脚 HTML。2026-10-02 完成本地构建及浏览器验收。

## 需求落实

| 项目 | 实现及验收结果 |
| --- | --- |
| 落地页 | 定位为帮助使用各类 AI 应用的助手，说明设备选择、网络配置与使用指引；三步引导、常见问题和登录入口。公开文案测试排除敏感技术词，不宣称提供尚未实现的 AI 对话能力。手机布局采用单列、可展开菜单和清晰主操作。 |
| 登录、注册、忘记密码 | 用户专用表单，保留管理员原登录。注册分为账户信息和邮箱验证／确认两步，支持修改账户信息、密码显示及强度提示、可选邀请码、失败重试和验证码重发。找回密码分为邮箱和验证码／新密码两步，完成后提示登录。 |
| 加载体验 | 用户业务页延迟加载，首次加载使用骨架屏；后台刷新保留已有内容。部分用户只读接口使用 15 秒内存缓存并合并并发请求，按认证身份和语言隔离，提交后清除、重新聚焦时刷新。缓存不写入持久化存储。 |
| 总览 | 将“我的订阅”放在总览前部，整合当前套餐、用量、到期时间、设备限制及导入入口。原订阅路由跳转总览；连接详情、重置地址与节点详情保留在展开区域。 |
| 配置导入 | 根据系统推荐客户端，支持切换全部客户端；所选客户端决定对应配置格式，手动复制、二维码与导入保持一致。记忆客户端选择，不存储订阅地址。唤起只能由点击触发，提示用户确认结果并提供复制和使用指引。 |
| 内置浏览器 | 识别微信、QQ、微博内置浏览器，展示在系统浏览器中打开的提示及复制链接入口，阻止进入用户登录、付款和导入流程。独立 QQ 浏览器不误判。 |
| 头像及套餐标识 | 邮箱首字母大写头像；有套餐且未到期时显示真实套餐名称，长期套餐同样支持。过期和无套餐不显示有效套餐标识。菜单提供账户、订单、用量、邀请和退出入口，支持 Escape 和点击外部关闭。 |
| 导航 | 桌面主导航从 9 项收敛至总览、购买、文档、工单、设置 5 项；手机底部为总览、购买、工单、账户 4 项。订单、用量、邀请转入账户菜单，原路由及功能保留。 |

## 设计与实现边界

主导航围绕查看状态、开始使用、寻求帮助和管理账户组织，减少重复的总览／订阅入口。移动端订阅卡置于统计之前，使导入操作更容易找到；使用安全区域、足够的触摸尺寸和单列排版。认证页面减少首屏干扰，逐步显示必要字段，校验失败保留已填内容。密码强度是规则提示，不是安全保证。

验证码提示与实际后端一致：有效期 5 分钟，重发按钮等待 60 秒；没有复制参考图中的“10 分钟／最多 5 次”策略。关闭邮箱验证时注册仍有确认步骤；配置了安全验证时，邮件发送后需重新完成该验证。注册成功但自动登录失败可以重试登录，不会重复创建账户。配置了服务条款时保留最终确认。

新增文字完整覆盖简体中文、繁体中文、英语、日语、韩语、越南语、俄语和波斯语，沿用既有语言切换及 RTL 方向机制。金额输入统一显示货币单位，仍按接口要求转换为分。

UA 仅用于推荐，不用于推断客户端已安装；所有客户端和手动方案始终可用。包括 Android、iOS、桌面系统以及使用桌面 UA 的 iPad。依据 [MDN 的 UA 检测说明](https://developer.mozilla.org/en-US/docs/Web/HTTP/Guides/Browser_detection_using_the_user_agent)保留回退入口，并参照 [Hiddify 官方支持平台](https://hiddify.com/app/How-to-install-Hiddify-app/)及 [sing-box 客户端文档](https://sing-box.sagernet.org/clients/android/)安排推荐。

骨架屏和保留刷新内容参考 [web.dev 布局偏移优化指南](https://web.dev/articles/optimize-cls)。本轮没有进行真实用户 LCP／CLS 性能测量，不将构建包体或本地观感当作线上性能指标。

本轮没有发送真实邮件、修改真实密码、付款或打开原生客户端。真实 SMTP 投递、各手机内置浏览器行为及安装客户端后的导入结果需要实际设备验收。

## 本地复验辅助

`php tests/user-experience-fixtures.php setup` 只允许 local 环境及既有 `test@example.com` 非管理员账户，备份套餐字段后赋予专用隐藏套餐；`cleanup` 恢复原字段并清理该套餐。不修改凭据。应先执行 cleanup 再重复 setup；备份文件在 Git 忽略范围内。
